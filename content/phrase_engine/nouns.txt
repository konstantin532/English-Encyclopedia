# ЧЕРНОВАЯ разметка существительных A1 + A1+ (status: draft, автор: Claude, 2026-10-27).
# Формат: лемма | теги (тип значения) | исчисляемость | флаги
# Исчисляемость: C — исчисляемое, U — неисчисляемое, CU — оба употребления, PL — лемма во мн. числе,
#                P — имя собственное (без артикля, с заглавной).
# Флаги: size=S/M/L/X — размер предмета; cap=S/M/L — вместимость (во что можно положить);
#        holds=… — что именно бывает внутри; surf — на нём что-то лежит/сидят (on);
#        under — под ним есть место (under); lm — ориентир для near/behind;
#        wall — висит на стене; zero — без артикля в устойчивом сочетании (at home);
#        coll — собирательное, в AmE согласуется в ед. ч.; review=… — требует решения редактора.
#        rel — «свой» человек: естественно с my/your (my teacher); остальные люди — с the (the farmer).
#        pl_ok — естественно во мн.ч. с притяжательным (my brothers, но не *my moms).
#        public — общее, не «моё»: *my counter, *his taxi, *her stairs.
#        nonagent — не бывает деятелем большинства действий: *The baby buys a bike.
