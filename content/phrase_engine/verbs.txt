# ЧЕРНОВАЯ разметка глаголов A1 + A1+ (status: draft, автор: Claude, 2026-10-27).
# Формат: лемма | рамки | continuous | прош.вр. | примечание
# Рамки (через ;):
#   T:<что>        — переходный: что может быть прямым дополнением (#тег = тип существительного, слово = конкретная лемма)
#   I              — может стоять без дополнения
#   P:<предлог>:<что> — дополнение через предлог (listen TO music)
#   L:<предлог>:<что> — обязательное обстоятельство места (live IN a city)
#   S:<кто>        — кто бывает подлежащим (по умолчанию #person)
#   SI:<кто>       — неодушевлённое подлежащее без дополнения: The store opens at nine. My back hurts.
#   X              — не использовать в свободной генерации (только в готовых фразах уроков)
# continuous: yes / no (глагол состояния — в норме не ставится в -ing в этом значении)
# прош.вр.: форма Past Simple; reg = правильный (-ed)
