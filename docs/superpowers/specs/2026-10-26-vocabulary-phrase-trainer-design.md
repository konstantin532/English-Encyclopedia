# Интегрированный тренажёр слов и фраз — одобренный пилот

Автор одобрил дизайн и реализацию в разговоре 2026-10-26. Base: main fbec5724b67b9caf7045fa3a4da386607eedb759; PR #129 уже слит. Удалённый переключатель глубины урока не возвращать. Merge, auto-merge и применение миграций к рабочей/production базе не разрешены.

## Цель и границы

В существующем Django-сайте связать понимание смысла, контекст, мнемонику, самостоятельное применение (включая произнесение) и интервальное повторение. Русскоязычные взрослые A0–A1; инструкции и обратная связь по-русски, оригинальные примеры на современном американском английском. Не переписывать уроки или их порядок; не добавлять внешние платные API, LLM, фреймворк, очередь или распознавание речи.

Пилот: после знакомства с уроком №5 `a1-cafe-order`, внутри недели 3. Ровно LX-00055 tea (напиток), LX-00285 I would like a coffee, please. (заказ), LX-00084 Sorry? Can you say it again, please? (переспрос). Источники: content/seed_lexicon/a1_w03_pilot.yaml, a1_w03_cafe_plus.yaml; content/seed_lessons/a1_w03_l05_cafe.yaml. I’d вводится в уроке №5; числа урока №6 и How much урока №10 не предполагать известными.

## Выбранная архитектура

Добавить сохраняемый серверный поток внутри apps.learning; переиспользовать LexicalUnit по конкретному смыслу, UnitProgress как единственное лексическое расписание и IndependentAttempt как журнал попыток. Альтернатива — дополнить старые карточки — не решает серверный учёт помощи и возобновление. Отдельный SRS создаёт конкурирующий прогресс и исключён.

Контент пилота — версионируемый manifest с постоянными ID заданий и семейств, русскими объяснениями, пререквизитами, моделями, допустимыми вариантами, мнемониками и сменой ситуации. Все три оригинальные смысловые мнемоники получили AI-рецензию при проектировании; это не проверка преподавателем/носителем или результат обучения людей. Нет мнемоники или редакторского комплекта — единица недоступна, не молчаливый пропуск метода. Cosmetic version mapping сохраняет непрерывность; другое значение — другой LX; изменение проверки требует явной карты совместимости. Исторические snapshots/aggregates не переписывать.

Существующие lexical chunks JSON сами не имеют ID. Не создавать новые LX для сокращений и не повышать слова внутри фразы автоматически. Lesson completion = exposure, не mastery. Прежние aggregates и assistance=not_stated не становятся доказательствами unaided recall.

## Учебный путь

Знакомство: ситуация → объяснение/пример → смысловая мнемоника и возможность личной → скрыть образец → немедленная попытка без помощи → добрый разбор → применение в новой ситуации → расписание. При повторении сначала новая русская ситуация и независимый ответ, затем помощь/мнемоника/модель по запросу, разбор и соразмерное применение. Не четыре длинных упражнения на каждый review.

Постоянно доступны «Не помню», помощь и продолжение; максимум две попытки перед разбором. Скопированный или раскрытый образец, повтор вслед за образцом и немедленные повторы не независимое извлечение. Открытый ответ: критерии и несколько образцов плюс самооценка; неизвестный вариант не ошибка. Отдельно хранить «коммуникативная цель достигнута» и «целевое выражение использовано». Tea, please. может быть хорошим заказом, не доказав would like. I like coffee. — предпочтение, не изученный заказ.

Произнесение: «Скажите сами → откройте образец → сравните», явно самооценка. Не записывать/передавать голос. Доступная текстовая альтернатива не получает spoken evidence. Нет проверенного аудио — сохранить текст и самостоятельную речь; не имитировать прослушивание. Если появится законное проверенное аудио exact-version, отдельное listen → pause → repeat обозначается как имитация, не shadowing или самостоятельный recall. Русско-английская смесь — опора, не полный английский ответ.

## Состояние и свидетельства

Расширить IndependentAttempt обратно совместимыми nullable/default полями: origin=trainer, target LX, encounter/session, server evidence metadata (task/family/version/kind/reliability/goal/target/scheduling decision). Использовать существующие prompt/model snapshots и batch-token/unique pattern; trainer rows явно исключить из обычных lesson_check_attempts, сохранив экспорт и историю.

Добавить принадлежащие пользователю enrollment/preferences, сохраняемую encounter/session и private mnemonic. Сессия хранит фиксированную версию, этап, помощи, revision и логический токен шага. Помощь фиксировать перед выдачей и не очищать поздним ответом. Возобновление не открывает модель до попытки и не создаёт второй результат. Abandon не ошибка. Ошибки HTTP/сети не ошибки ученика; повтор после таймаута проверяет тот же operation token. Ответы и черновики не отправлять в аналитику/логи. Черновики неактивной сессии удалять через 30 дней; принятую историю сохранять до существующего удаления аккаунта. Не удалять историю вместе с истечением черновика.

Мнемоника: plain text ≤300, owner-only, Django autoescape/textContent, никогда mark_safe/help_text|safe, HTML, публичный LexicalUnit или внешний сервис. Private responses no-store; владельца проверять на GET/POST/resume/status и для каждого ID. CSRF, ограниченные размеры, ограниченная серверная частота действий. Все direct user FK данные включить в существующий export/delete; nested данные требуют явной проверки.

## Расписание

Сохранить существующую лестницу 1,3,7,14 дней. Новое знакомство назначает +24h, без delayed-success; существующий stage/due не сбрасывать при подключении. Первый объективно правильный независимый due recall новой встречи может увеличить ступень один раз. Нужны наступивший срок и ≥24h после последнего зарегистрированного показа целевого материала предыдущей встречи. Чередовать разные authored context families; варианты одного семейства не новые контексты. Несколько действий, retries, immediate recall одной встречи не несколько spaced successes.

Подтверждённая ошибка уменьшает stage максимум на одну ступень за встречу; следующая lexical практика минимум +24h. Помощь/reveal/self-report/uncertain/recognition/valid goal without target не увеличивают verified stage; при наступившем сроке можно перенести практику на +24h без повышения. Раннее добровольное упражнение не отодвигает due. Initial recall не доказывает delayed retention. В UI: «Новое», «Пора повторить», «Нужна практика», «Повторим позже» и причина; без процентов памяти, CEFR или mastery от просмотра.

Для enrolled user + selected LX все записи UnitProgress идут через общий gate, включая старые APIs: legacy model matches не дают новых trainer spaced successes. Вне opt-in/flag пилота поведение сохраняется. Участие отключается с сохранением истории. Существующий MistakeReview +48h по ошибкам A1 остаётся отдельной очередью грамматических упражнений; показывать рядом и не дублировать lexical credit.

UTC instants владеют сроками; IANA timezone предпочтения (по умолчанию Europe/Moscow) — только местный день и отображение. DST не меняет UTC due или минимальные24h. Daily limit 1–10 встреч (default10), новых в пилоте максимум3; overdue first, пауза не обнуляет знания и не даёт catch-up advancement. Продуктовые предположения: min24h, budget10, bounded retries; это не научно оптимальные интервалы.

## Атомарность и совместимость

Одна транзакция: принять idempotency key/payload → записать attempt → session revision/state → UnitProgress. Дубликат с тем же payload возвращает сохранённый результат, конфликтующий или stale запрос получает понятный409 с каноническим состоянием. Уникальность БД, PostgreSQL row locks, для SQLite сериализация записи/CAS + bounded retry; один select_for_update в SQLite недостаточен. Не доверять присланным интервалам/assessment fields.

Только добавочные миграции с безопасными defaults, без преобразования старых evidence. Тестовые миграции — только disposable DB. Перед реальной миграцией отдельное разрешение, backup и restore rehearsal. Feature flag disabled by default + добровольный opt-in; rollback выключает поток, не удаляя таблицы/историю. Accounts authentication, permissions, secrets, dependency manifests не менять.

## Приёмка и границы доказательства

Детерминированные тесты controlled time: cold start, due/early,24h/48h, ladder, hints/reveal, first vs retry, family duplication, DST/day budgets/absence, version mapping, idempotency and real concurrent requests, atomic rollback. Isolation/CSRF/private text/export/delete, accepted variants/uncertainty, missing audio, interrupted resume/back/network failures. Обязательная регрессия существующих SRS/MistakeReview.

Полный четырёхметодный путь с реальным контентом, переносом и simulated delayed review. Desktop и390px плюс320px, keyboard/focus/contrast/non-color feedback/reduced-motion/200% text без потери controls. Отдельно сообщать manual visual, browser automation и HTTP checks.

Критерии: полный reviewed content всех3units;4метода связаны; помощь не unaided; варианты импровизации и новая ситуация; одна отправка→не более1advance; cross-user rejected; прерывания без потери confirmed progress; старые features работают. Human trial отдельно: добровольцы6–10, immediate/+48h/+7d с параллельными unseen задачами, отмечать intervening practice и actual delay/missingness; без causal claim/гарантии. Simulated time не доказательство человеческого удержания.
