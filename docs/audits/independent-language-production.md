# English Encyclopedia — независимое владение A1: аудит по исходному коду

**База:** [`2f6061dab132`](https://github.com/konstantin532/English-Encyclopedia/commit/2f6061dab1326581fb8cf70c4c9fa46061b00d77), `main`, 21.10.2026.  
**Статус:** ограниченный дистанционный аудит исходников и опубликованных CI; ни один реальный ученик не тестировался.  
**Цель:** установить, где платформа проверяет узнавание/совпадение с образцом, а где получает независимое, проверенное свидетельство владения языком. **Этот документ не утверждает эффективность обучения.**

## Возможности и ограничения

- GitHub connector: доступны читаемые исходные файлы, истории PR, CI и тестов; доступ на запись только в новую ветку по запросу автора.
- Проверены код и структура `apps/drills/models.py`, `apps/api/views.py`, `apps/learning/{independent_views,models,services,transfer_pilot,mistake_review}.py`, `apps/learning/understanding.py`, 28 записей `content/manifests/a1_understanding_checks.json`, 28 записей `content/manifests/a1_scaffold_transfer.json`, выбранные исходные уроки, `docs/pilots/a1-four-weeks/assessment.yaml`, соответствующие тесты.
- Git-клонирование в локальную среду не удалось из-за DNS для github.com. Локально **не запускался полный Django** и не подключались PostgreSQL, Supabase, внешнее аудио и браузер.
- Результаты GitHub CI относятся к конкретным коммитам, **не** к испытаниям реальных учеников.
- Реальные произношение, удержание навыка, эффект обучения и конкурентное превосходство не доказаны; CEFR не присваивается автоматически.

## Подтверждённый дефект AUD-IP-001 — неполный ответ засчитывался как полный (P2)

- **Источник:** `content/seed_lessons/a1_w14_l28_review.yaml` → `exercises` → `uid: EX-00161`, `order: 4`, `stage: transfer`.
- **Задание:** «...ответьте, откуда вы, **и добавьте, что говорите по-английски**».
- **До исправления:** `accepted` включал `I am from Russia.` и `I'm from Russia.`. Функция `Exercise.is_correct` сопоставляет нормализованный ответ со списком и вернула бы `True` для обоих. Это демонстрирует **ложное подтверждение двухчастной задачи**.
- **Воспроизведение:** в изолированном Python-пробнике применена точная реализация `Exercise.normalize` и оригинальный список вариантов. Оба неполных ответа прошли проверку; `I am from Russia. I cannot speak English.` не прошёл. Это **не** результат живой HTTP-сессии; новый Django-тест готов проверить путь API в CI.
- **Первопричина:** семантический контракт задания не отражён в списке вариантов. Не ошибка нормализации.
- **Исправление в этой ветке:** удалить два неполных варианта, сохранив сокращения и полные естественные варианты. Новый `tests/test_a1_final_transfer_integrity.py` проверяет ключ и ответ через Django Client.
- **Ограничение:** произвольные другие грамматически допустимые ответы по-прежнему получают `needs_review`, а не "неверно". Это предохранитель против необоснованных отказов.
- **Влияние:** завышение успешности именно этой задачи, возможное сохранение совпадения с образцом и учебного прогресса при незавершённом высказывании; нет доказательств масштаба в действующей системе. **P2**, не P0.

## Неподтверждённые, но существенные образовательные разрывы

1. **Нет результатов людей.** Нельзя вывести способность составлять новые предложения из числа тестов или подготовленных диалогов.
2. **Независимое письмо ≠ диалог.** Четыре текстовых задания не измеряют темп, восприятие спонтанной речи, произношение и очередность реплик.
3. **Новая ситуация ≠ автоматически проверенная.** Проверка свободных ответов ожидает человека, а добровольная отметка "без помощи" — самоотчёт.
4. **Перенос 7/30 дней ограничен тремя учебными темами.** На остальные недели A1 нет доказанного 30-дневного независимого измерения.
5. **Часть отложенного повтора остаётся заданиями с тремя вариантами.** Для измерения продуктивного вспоминания нужен отдельный закрытый банк ответов без вариантов.
6. **Наличие озвучки не равно проверке восприятия речи.** Аудио в контексте этой проверки не предоставлено для прослушивания и валидации.
7. **Словарный пробел.** Количество объяснённых слов не доказывает способность самостоятельно подбирать нужные слова в новой фразе.

## Что уже хорошо устроено

- `UnitProgress.register` не переводит упражнения с образцом автоматически в уровень самостоятельного владения.
- Незнакомые творческие формулировки не должны автоматически штрафовать ученика как ошибки.
- Образцы на независимой странице не показываются до отправки всех четырёх ответов.
- Самостоятельные работы имеют версии задания и очередь ручной проверки.
- Сроки initial/day_7/day_30 сохраняются раздельно, пропущенная 7-дневная проверка не выдаётся за посещённую.
- Тесты проверяют права учеников, дублированные отправки, архивные задания и семантику ряда ответов.

## Отдельный план эмпирической проверки

См. `docs/pilots/independent-language-production-protocol.md`. Рекомендуется отдельный непубличный банк заданий: публикация проверочных ответов и сцен в открытом GitHub позволяет запомнить тест вместо применения навыков.

**Измерять отдельно:**
- IPR — долю назначенных заданий, выполненных независимо и подтверждённых слепой оценкой.
- NTR — долю новых, не предъявлявшихся при обучении ситуаций с достигнутой целью.
- D7/D30 — независимый успех на эквивалентных, а не идентичных проверочных формах.
- CTS — коммуникативную успешность с учётом границ A1 по CEFR.
- FPR/FNR автоматического оценщика против слепой человеческой разметки.
- Отдельно помощь, недошедших до проверки и отказавшихся от ответа.

**Не присваивать общий балл образовательной эффективности без измеренных реальных результатов.**
