## Подтверждённая проблема

`IndependentAttempt` хранит несколько разных видов свидетельств:

| Вид | Варианты / префикс | Что сохраняется |
|---|---|---|
| Обычные четыре задания урока | 0–2, старые записи могут иметь пустой token | Понимание, письмо, перенос, объяснение и самооценка |
| Отложенный пилот | 100–102 / pilot- | Этап, плановое и фактическое время, опоздание, отсутствие измерения промежуточной практики |
| Диалог в кафе | 200+ / cafe- | Транскрипт, подсказки и проверяемые речевые действия |

Обычная форма `independent_check` выбирала для `rate`/`rubric` любую собственную SELF_REPORTED запись того же урока со skill transfer/explain. Поэтому специально составленный POST с ID пилотной записи возвращал **200** и заменял её `self_rubric` обычной самооценкой. Исчезали `pilot_stage`, `planned_at`, `actual_submit_at`, `timing`, `intermediate_practice`. Тот же путь мог перезаписать метаданные кафе. Это воспроизведённая **P2 проблема целостности свидетельств**, а не доказательство атаки или потери production-данных. Доступ к чужому пользователю не был разрешён.

История последних 12 обычных ответов включала экспериментальные записи, а счётчик «четыре навыка / уроки из 28» учитывал пилоты и кафе. Это смешивало разные виды практики, даже без перезаписи.

Независимый рецензент отдельно воспроизвёл первоначальный дефект в SQLite `:memory:`: создание пилота — POST302, обычная рубрика для его ID — POST200, все пять исходных служебных ключей исчезли. Регрессионные тесты основного автора воспроизвели тот же путь до исправления.

## Исправление

Новый `apps/learning/evidence.py` задаёт локальную выборку обычных проверок: четыре поддерживаемых skill, варианты 0–2, без префиксов pilot-/cafe-. Она используется:

- перед любой записью обычной рубрики/рейтинга;
- в истории обычной проверки;
- для признака повторной ситуации, включая страницу ошибки формы;
- для счётчиков обычных проверок на dashboard.

Ограничения пользователя и урока сохранены поверх этой выборки. POST для экспериментального ID теперь получает **404 до изменения записи**. Если у старой или неконсистентной записи есть только один экспериментальный признак — зарезервированный вариант либо префикс — обычная форма всё равно её не редактирует.

Default manager модели не фильтруется. Преподавательское ревью продолжает видеть все типы по исходным snapshots; экспорт данных сохраняет все собственные записи вместе с метаданными. Старые обычные попытки с пустым token доступны. При добавлении новых обычных вариантов за пределами 0–2 эту явную границу необходимо расширить вместе с проверками.

Модели, миграции, accounts, контент, шаблоны, CSS/JS, аудио и правила оценки английского не менялись. Ранее потерянные метаданные не восстанавливаются автоматически: источника для достоверного восстановления здесь нет.

## Пробел, обнаруженный при сквозной проверке

**Недельные тесты по 10 вопросов и итоговый A1 на 30 вопросов сейчас не реализованы как пользовательская функция.** Это отдельный незавершённый пункт прежнего плана, а не сломанный существующий тест.

Доказательства на текущем дереве:

- В `apps/learning/urls.py` нет маршрутов недельного/итогового экзамена; runtime-инвентаризация пользовательских URL не нашла exam/quiz/weekly/final/test.
- `templates/curriculum/week.html` и каталог уровня не предоставляют таких тестов.
- У моделей нет попытки целого теста с комплектом ответов и итоговым результатом. ExerciseAttempt хранит отдельное упражнение, WeekGoal — самооценку, IndependentAttempt — отдельное самостоятельное задание.
- `docs/pilots/a1-four-weeks/assessment.yaml` — отдельный документ пилота по 3 вопроса в комплекте. Его структурные тесты не подтверждают наличие функции на сайте.

Этот этап исправляет потерю свидетельств, а не добавляет новый экзаменационный механизм. Следующая самостоятельная задача — законченная система 10/30: редакторский банк только изученного материала, честная политика оценки открытых ответов, сохранение полного комплекта попытки, авторизация и повторная отправка, страницы результата и отдельный тестовый набор. Совпадение с образцом и самооценка не должны объявляться доказанным владением A1.
