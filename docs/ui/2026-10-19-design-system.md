## Источник стилей и сборка

Все13 публичных исходных CSS перенесены в static/scss/legacy/; редактировать их и новые system-модули. CSS по старым URL остаётся сгенерированным совместимым артефактом. Административные стили вне миграции.

static/scss/foundation.scss объявляет порядок слоёв: accessibility → fonts → tokens → base → studio → cinema → pages → motion → polish → markers. Accessibility первой обеспечивает приоритет важных защитных правил; markers последней сохраняет учебную цветовую/монохромную семантику. Не добавлять новые публичные unlayered-правила поверх этой системы.

Модули system: tokens — Sass maps, функция token с проверкой ключей, mixins и CSS-переменные; typography — иерархия, читательский масштаб и адаптация; surfaces — генерируемые варианты существующих карточек и состояния; motion — согласованные времена, выразительная бумажная карточка и reduced-motion.

Сборка: Node24, pnpm11.25.0, Sass1.105.2, точные версии и pnpm-lock.yaml.

    pnpm install --frozen-lockfile --ignore-scripts
    pnpm build:css
    pnpm check:css
    pnpm test:ui

watcher не используется, его install script не исполняется. CI проверяет расхождения SCSS/CSS. Render обслуживает закоммиченный CSS и WOFF2, Node в production не нужен. .gitattributes закрепляет LF для выходных CSS на Windows/Linux.

Чтобы изменить шрифт: legacy/_design-tokens.scss и legacy/_fonts.scss. Чтобы изменить масштаб/плотность/движение: system/_tokens.scss; компоненты используют смысловые переменные. Учебную палитру не менять.

## Движение

Сохраняются Full/Balanced/Minimal и системное сокращение движения. Новая постановка бумажной карточки привязана к реальному вступлению Full, не повторяется при возврате к тому же пути в одной вкладке. Существующие короткие hover/state-анимации продолжают работать. При запрете sessionStorage декоративное вступление пропускается, работа интерфейса сохраняется.

Результат упражнения остаётся серверным; успех не выводится из анимации. Новая карточка и стрелка действий не перехватывают фокус, прокрутку и навигацию.

## Публичные метаданные

PUBLIC_SITE_URL задаётся владельцем как точный origin production, без пути/секретов/параметров. Пустое или некорректное значение не публикует canonical; sitemap возвращает404. Это намеренно: адрес из заголовка Host не считается доверенным публичным адресом. Пример: PUBLIC_SITE_URL=https://your-domain.example.

/robots.txt исключает /admin/, /accounts/, /learning/, /api/, /healthz/ и ссылается на sitemap только при заданном origin. Это подсказка поисковику, не механизм авторизации. Личные страницы остаются защищены прежними правилами. В sitemap только существующие публичные маршруты и опубликованные уроки/истории/стихи; словарь и уровни следуют существующим публичным представлениям.
