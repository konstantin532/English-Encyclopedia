# Редактирование историй и уроков в админке

## История
1. Откройте «Истории» и нужную историю.
2. В разделе «Текст и реплики» каждая реплика находится в компактной карточке. Нажмите строку, чтобы открыть текст; остальные реплики свернутся.
3. Персонаж, тип реплики, эмоция и музыка находятся в раскрывающемся разделе «Кто и как говорит».
4. Пишите обычный текст. Служебные коды редактор хранит внутри.
5. Для настройки разметки раскройте «Разметка слов». Чтобы назначить разметку, выделите слово в поле текста, выберите часть речи и значение, нажмите «Назначить». Можно нажать размеченное слово в предпросмотре: оно выделится в поле ввода.
6. Разговорный вариант и перевод открываются кнопкой «Произношение и перевод». Укажите разговорный вариант, только если он отличается от основного текста.
7. Кнопки «Выше», «Ниже», «Убрать» меняют порядок карточек. Последнюю удалённую карточку можно восстановить кнопкой «Вернуть удалённую карточку», не теряя остальные правки. «Вернуть исходное содержимое поля» возвращает состояние поля при открытии страницы.
8. Вопросы, ответы и выражения редактируются отдельными карточками. Имена, слова для пересказа и шаги пересказа пишутся по одному на строке.
9. Снимите «Опубликовать», чтобы сохранить черновик. После проверки можно опубликовать.

Изменённым словам разметка не назначается автоматически: часть речи и значение зависят от контекста. У неизменённых фрагментов разметка сохраняется. Повреждённая разметка не принимается сервером.

Если реплики заданы, общий текст истории собирается из них при сохранении. Для истории без диалоговых карточек можно использовать сворачиваемый раздел «Сплошной текст вместо реплик».

### Быстрый ввод целой истории
Раскройте «Вставить историю обычным текстом», выберите рассказчика, вставьте текст и разделите абзацы пустыми строками. Кнопка «Добавить абзацы в историю» создаст отдельную реплику для каждого абзаца и добавит их в конец. Существующие реплики не заменяются. Новые реплики создаются как рассказ без автоматической разметки; при необходимости поменяйте персонажа и тип речи.

Счётчик над карточками показывает число реплик и наличие несохранённых изменений. Для сохранения в базе по-прежнему нужна кнопка «Сохранить» внизу формы.

## Урок
1. Откройте «Уроки → Добавить» и заполните название, описание, уровень и неделю.
2. Новый урок открывается как черновик.
3. Ниже добавьте раздел объяснения, выберите его из семи разделов и напишите текст.
4. Разметку английских слов назначайте через кнопки редактора. Пустая строка разделяет абзацы. Строка с «> » создаёт английский пример, строка с «- » — пункт списка.
5. Добавьте практическое задание: тип, этап, инструкцию, правильный ответ. Варианты и допустимые ответы — по одному на строке.
6. Сохраните, проверьте урок на сайте и затем опубликуйте.

## Озвучка
Существующий звуковой манифест закрыт для ручного редактирования. При изменении текста история отключает прежнюю озвучку. Если основной текст изменён, а прежний разговорный вариант не изменялся, он снимается, чтобы не показывать другой текст.

Новая озвучка отредактированной в админке истории пока не создаётся автоматически. Генератор исходных YAML озвучивает исходные материалы; подготовка и подключение озвучки текущего текста — отдельный шаг. Скрипты запуска/генерации не заменяют редакторский текст исходниками.

## Где сохраняются правки
Изменения сохраняются в базе данных, а не в YAML и не автоматически в Git. Храните резервные копии базы.

start.bat и generate_audio.bat вызывают load_content --preserve-admin-edits. Этот режим сохраняет истории и уроки, для которых в журнале Django Admin есть запись создания/изменения. Журнал нужен для этой защиты; не очищайте его без переноса признака редакторских правок в другое хранилище. Новые исходные материалы продолжают загружаться, а связанные части защищённого урока пропускаются целиком.

Явный вызов load_content без этого флага остаётся полным импортом исходников и может заменить редакторские изменения. Это действие предназначено для разработчика.

## Стихи и скороговорки

В разделе «Стихи и скороговорки» текст вводится целиком без технических тегов. Переносы строк и пустые строки между строфами сохраняются. Учебная разметка доступна через «Разметка слов».

Разверните «Произношение и пропуски по строкам»: у каждой непустой строки есть ударения, IPA, русская подсказка и список слов для одного пропуска. Произношение заполняется вручную; редактор не генерирует его автоматически. Неизменённые строки сохраняют подсказки при вставках и удалениях, изменённые строки теряют старые подсказки и пропуски. Пустые строки не участвуют в нумерации. Повторяющиеся одинаковые строки сопоставляются по порядку.

Новые произведения открываются как черновики. После сохранения через админку обычный запуск с --preserve-admin-edits сохраняет редакторский текст, произношение и задания стихов. Явный load_content без этого флага по-прежнему заменяет данные исходными YAML.
