# Журнал уроков для ИИ-агентов

Сюда попадает каждая ошибка, которую нашёл проверяющий агент или автор, а не тесты. Одна строка на случай, новые — внизу. Правило из AGENTS.md §10: первый случай — запись здесь; второй случай той же категории — тест, аудит или хук.

`tests/test_agent_setup.py` следит за журналом: у каждой строки дата, категория из латинских букв и дефисов, описание и закрепление; в категории, где случаев два и больше, хотя бы одно закрепление называет существующий тест (`test_…`) или файл проверки в обратных кавычках.
