Дата: 2026-10-31. Ветка: fix/group-entry-navigation.

## Запрос и установленная причина

Автор долго искал ссылку «Моя группа», затем получил «В группу вступают только ученики» из своего отдельного ученического аккаунта. Автор подтвердил: учительский и ученический аккаунты должны оставаться отдельными.

Read-only проверка локальной SQLite подтвердила ошибочный is_staff=True у ученического аккаунта при is_teacher=False/is_superuser=False. Это не отказ из-за кода или закрытого набора. После внешней резервной копии через SQLite backup API (quick_check=ok) условным UPDATE снят только этот флаг; ученический is_learner стал True, другой активный учитель-владелец сохранён. Почта, пароль, прогресс и состав групп этим исправлением не менялись. Реальная база и резервные копии в Git не добавляются.

Последующая read-only проверка настоящего 8000: группа со снимка существует и принимает учеников, исправленный аккаунт уже состоит в ней. Вступление повторил сам пользователь; проверочный код не создавал его членство.

## Границы

Публичного каталога и типов публичная/приватная группа сейчас нет. is_open означает «принимает новых учеников». Ученик с действующим кодом вступает сразу, без дополнительного одобрения, и может состоять в одной группе. В этой задаче политика доступа и модели не меняются.
