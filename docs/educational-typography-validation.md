## Поведение, проверенное браузером

История1: «Без текста» скрывает все line-text; «С текстом» и «Как написано» показывают written и скрывают spoken; возврат к «С разметкой/Как говорят» работает. У первого урока после переноса сохранены кнопки глубины; до расширения повторные циклы и Tab/Enter прошли на обоих уроках. После общего слоя повтор полного сценария обоих уроков не завершён.

## Остановка компьютерной проверки

Инструмент прекратил Computer Use: URL-policy enforcement не поддерживается для текущего Windows browser. Остановленный вызов включал следующий просмотр диалога/истории при200%, затем Ctrl+0 и закрытие созданной вкладки; исход этих действий не подтверждён. Ограничение не обходилось другой автоматизацией. Возможный оставшийся масштаб200% сообщён пользователю. Файловые, терминальные и GitHub операции продолжены отдельно по прямому разрешению.

Снимки действительно просмотрены в разговоре; локальные файлы снимков и Library IDs не созданы. Попытка материализовать входной Library PNG штатным helper упала на os.setxattr в Windows; конечного файла нет. Ни этот PNG, ни снимки из другого исполнителя не выдаются за доступные локальные файлы.
