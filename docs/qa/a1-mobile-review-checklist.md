# A1 — приёмка индивидуальных повторений на телефоне

Эта проверка нужна перед распространением пилота на реальных учащихся.
Автотесты Django проверяют сервер и HTML/CSS-контракты, но **не заменяют**
физический Android, реальную доступность и педагогическую проверку.

## Начальные условия

Открыть тестовое развёртывание актуального коммита (main либо проверяемая ветка PR) с выполненными миграциями.
Войти под отдельным тестовым аккаунтом. Использовать Android Chrome (или
системный браузер) и компьютер с клавиатурой. Не использовать данные
реальных учеников для испытаний.

## Поведение 48-часовой очереди

- Ошибиться в обычном проверяемом задании урока 9, например в вопросе
  «Is there milk?». Убедиться, что показана подсказка без готового ответа.
- Перейти в «Мой прогресс → Повторить ошибки» — до срока не должно
  открываться ни одного из пяти новых вопросов; должна быть дата.
- Использовать безопасный тестовый перенос даты в БД или отдельную
  тестовую среду. Не переводить системные часы производственного сервера.
- Открыть первую новую карточку: правильный ответ **не выделен**.
  Нажать неверный вариант; получить правильный ответ и объяснение
  именно этого нового примера, а не исходного упражнения.
- Убедиться, что следующая карточка появляется по кнопке, а двойная
  отправка формы не пропускает несколько шагов.
- Проверить пять вопросов после исходных ошибок в двух упражнениях
  одного урока: наборы должны быть **разными** и проверять конкретный
  навык исходной ошибки, а не случайное правило темы.
- Если за пять заданий допущена ошибка, следующий круг появляется через
  два дня, без немедленного повтора и без искусственного падения CEFR.
- С другим аккаунтом нельзя видеть или отвечать на чужие сессии.
- Для свободного ответа, отличающегося от образца, не записывать
  автоматическую отрицательную попытку: добровольная пятёрка только
  после решения самого ученика.

## Узкие экраны и доступность

- Проверить портретную ориентацию на телефоне шириной около 320–430 CSS px
  и горизонтальную ориентацию.
- Длинные варианты (например с because, вопросом про автобус и
  «Can you repeat the question, please?») должны переноситься без
  горизонтальной прокрутки.
- Радиоварианты нажимаются по всей площади строки, кнопка «Проверить»
  не меньше 48px по высоте; в поле не требуется точное касание кружка.
- Проверить масштабирование текста Android до 200%, настройку большего
  системного шрифта и светлую/тёмную тему, если применимо.
- Включить TalkBack: озвучиваются вопрос, группа «Выберите ответ» и
  каждый вариант. Статус результата понятен без цвета.
- В браузере на компьютере пройти Tab → стрелки радиогруппы → Space/Enter.
  Видна фокусировка; Enter отправляет только один выбор.
- Проверить режим «Уменьшить анимацию» и отсутствие зависания при
  медленном Wi-Fi или обрыве соединения.

## Учебный пилот A1

Попросить 5–8 добровольных начинающих поработать с несколькими
пятёрками из разных недель. Записать не личные данные и не ответы,
а количество неоднозначных вариантов, непонятных формулировок,
неизвестных слов и заметных UX-препятствий.

**Готово к массовому использованию** только если нет критических
ошибок браузера, контраст/фокус/крупный текст удобны, все ответные
варианты имеют однозначную учебную интерпретацию и ученики
понимают цель отсроченного повторения. До этого статус — пилот.
