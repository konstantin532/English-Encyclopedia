# Полное чтение A1 без переключателя глубины

Правка поверх main `f611c973` с уже слитой типографикой PR #128.

## Поведение

- На всех 28 уроках A1 отсутствуют меню глубины и сообщения о скрытых слоях.
- Все семь исходных слоёв, произношение и сокращения показаны целиком.
- Оглавление сохраняет ссылки на каждый слой; переходы и перезагрузка не скрывают текст.
- Инициализация не читает и не меняет localStorage. Она снимает старое скрытие только с именованных верхних разделов объяснения и восстанавливает их ссылки.
- Ответы упражнений, вложенные подсказки, written/spoken, режимы проигрывателя и настройка размера текста не раскрываются и не переключаются этой логикой.
- Краткое объяснение и раскрываемые три дополнительных шага сохранены по одному экземпляру.
- Существующие блоки A1 используют подложку `#f3f0e6` и верхнюю линию `3px solid #916d34`, взятые из эталонного CSS первых двух уроков. Остальные исходные цвета и мобильная перестройка блока также сохранены.
- 32 урока A1+ не получают новый блок или stylesheet A1.

## Проверки

Перед публикацией на свежем main: Django 959 тестов, `OK (skipped=8)`; Node 139/139; штатная сборка CSS `--check` — 20/20; `git diff --check` без ошибок. Независимое read-only ревью не нашло конкретных P0–P3 замечаний. Для тестов повторно использованы существующие инструменты и отдельная зависимость CSP исполнителя; зависимости проекта и рабочего сайта не менялись.

В профильных Django-тестах проверяются все 60 опубликованных уроков, исходная разметка каждого слоя, краткие и подробные объяснения, оглавление и исключение A1+.

Node-тесты проверяют старое скрытие, inline display, недоступные ссылки, повторную инициализацию, повреждённый hash, отсутствие доступа к сохранённым настройкам и сохранение скрытых посторонних разделов. Отдельная изолированная мутация без фильтра ID была отвергнута проверкой защиты ответов.

В существующем Atlas acceptance сохранены реальные снимки до/после, проверки геометрии, переполнения, речевых режимов, контраста, масштаба и режима без JavaScript. Ожидания удалённых кнопок заменены отсутствием меню, видимостью семи слоёв, клавиатурным оглавлением, переходами по hash, перезагрузкой и точными цветами краткого блока.

До переноса в эту ветку на работающем локальном сайте (старый `6e96df2` с совместимой типографикой) выполнено HTTP-сравнение 60/60 страниц до/после. Тексты слоёв, краткая опора, практика, скрытые состояния ответов и ссылки оглавления совпали. Это свидетельство локального варианта; тесты этой ветки отдельно проверяют свежий main.

## Ограничения и границы

Свежий ручной визуальный осмотр этой правки не выполнен: Windows Computer Use остановлен из-за отсутствующей поддержки URL policy. Ограничение не обходилось другим браузером или локальным Playwright. HTTP и проверки кода не являются ручной дизайнерской приёмкой; результаты удалённого CI перечисляются в PR отдельно.

Учебные YAML/тексты, рабочая база, миграции, аккаунты, доступы, зависимости и конфигурация публикации не меняются. Основной локальный checkout и серверы 8000/8001 при подготовке PR не обновляются. Пользовательские `.gitignore`, `AGENTS.md`, `CLAUDE.md`, локальные базы, резервные копии и вспомогательные инструменты не включаются в ветку.
