# A1 — четыре слабых критерия: содержательное усиление и границы результата

**18 октября 2026, рабочая ветка:** `situation-weeks`. Изменения не предназначены для автоматического слияния в `main`.

## 1. Понятность для абсолютного новичка

Во всех 28 уроках добавлен **третий путь объяснения** — три коротких контекстных английских примера с точным русским смыслом и разбором «почему». Всего 84 отдельных шага. Они находятся в `content/manifests/a1_scaffold_transfer.json` и отображаются в раскрывающемся `details` на странице урока. Семь исторических слоёв **не удалены**. Первый экран сохраняет краткую подсказку, контраст двух фраз и ссылку к четырём самостоятельным заданиям.

«Суть / Почему / Полностью» теперь доступны не только урокам 1–4, но и **всем 28 урокам A1**. Без JavaScript исходные семь слоёв видны целиком, глубокая ссылка на скрытый слой возвращает полное чтение. Это опции представления, а не замена содержательного урока.

## 2. Языковая редактура и согласованность сюжета

В исходном банке `a1_understanding_checks.json` скорректировано 15 записей в девяти темах. Критичные примеры:

- Мия работает в кафе по истории курса: убран ответ «No, she doesn't» в контексте, где он без объяснения противоречил сюжету.
- Расположение магазина теперь указано в условии: ученик не должен угадывать «across from».
- В вопросах о привычках по воскресеньям используется естественное `on Sundays`.
- Для адреса сохранена обычная американская запись `5 Park Street`, а не `Five Park Street`.
- Для `like doing` новое описание соответствует проверяемому занятию `drawing`, а не неопределённому «хобби».
- В просьбе о воде принимается естественное `Can I have some water, please?`; модельные формулировки не считаются единственными верными.
- Вместо случайной продвинутой конструкции в ответе на тему кафе предложен уже изучаемый `Can I have tea, please?`.

**Дальше нужно:** профессионально проверить все исходные 28 YAML-уроков, 168 миссий, 815 карточек и реальное произношение с человеком, компетентным в American English. Проверка наличия текста и автоматические тесты не удостоверяют естественность каждой реплики.

## 3. Самостоятельное владение и подтверждения

- После полного пакета из четырёх открытых ответов сервер переключает **вариант задания на перенос**: новый сценарий для каждого из 28 уроков, всего дополнительно 28. Модельный ответ не отдается HTML до отправки. Сервер отклоняет устаревший `transfer_variant` в форме и сохраняет идентификатор варианта с попыткой. Для старых клиентов сохраняется совместимый одиночный POST, но основная форма использует только совместный режим.
- Свободные фразы не объявляются неверными только из-за несовпадения со строкой образца. Нет ложного автоматического присвоения CEFR.
- Ученик отмечает четыре измерения отдельно: **переданный смысл, конструкция, уместность, самостоятельность**. Это самооценка, а не алгоритмический вердикт.
- Преподавателю доступно отдельное **закрытое** Django-admin-рецензирование: отдельный вердикт, три явных критерия и обязательное обоснование. Редактор не может менять исходный ответ ученика через эту форму. Ученик видит свою рецензию в личной истории.
- Анонимные оценки или оценки других учеников из страницы ученика не извлекаются. Попытки остаются персональными.

**Нерешённое:** не построен объективный экзамен по аудированию, живому диалогу и произношению. Результаты не подтверждены независимым A1-пилотом. Проверка с человеком не заменяется автоматическим самоконтролем.

## 4. Мобильность и доступность

Узкие экраны 320–430 CSS px, увеличение шрифта и перенос длинных русских формулировок теперь отдельно учтены для самостоятельной проверки, четырёхкритериальных форм и трёхшаговых объяснений. Поля письма >=16px, касания >=48/52px, видимые фокус-рамки, `fieldset/legend`, отдельные подписи, идентификация языка `ru/en`, `prefers-reduced-motion`, `forced-colors`. При сильном масштабе три режима чтения перестраиваются в один столбец.

**Обязательная ручная проверка до пилота:** Android Chrome/TalkBack, 320/360/390/430px, текст 200%, обе ориентации, медленный интернет, сценарий без JavaScript, доступность ошибок форм, скачки фокуса и регрессии в цветовом контрасте. Код не доказывает, что этот сценарий уже прошёл испытания на устройствах.

Это список критериев, а не заявление об их выполнении.
