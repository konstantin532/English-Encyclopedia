## Проход 1: улучшения и первичный контроль

1. **Архитектура:** вместо двух контекстов на тему созданы три — 84 сценария на 28 уроков. `scaffold_bank` проверяет поля, ограничения, дублирование и отсутствие ключей/готовых вариантов. Выбор и описание каждого варианта выполняются на сервере.
2. **Исправлена видимая ошибка после POST:** раньше сессия переходила к варианту 2, а форма на экране ещё показывала вариант 1, приводя к ошибке при повторном заполнении. Теперь показана задача того же варианта, который ожидает сервер.
3. **Преподавательская оценка:** в Django Admin преподаватель видит точный исходный вопрос и один образец для сохранённой версии; если версия/задание не восстанавливается, оценка запрещена. Исходные ответы студента не перезаписываются.
4. **Мобильность:** инструкция во время отправки, блокировка повторного нажатия, восстановление кнопки из back-forward cache; доступный для экранного диктора текст вопроса; русская проверка орфографии только в русских полях; reflow и масштаб. Никаких копий личных ответов в `localStorage`.
5. **CI:** `uv sync --frozen`, `compileall`, каждый `tests/js/*.test.cjs`, проверки Django, миграций, 28 уроков, 815 вопросов, все Python-тесты.

## Проход 2: обнаруженные мелкие, но значимые проблемы

- **Гонка запросов:** одна лишь выключенная кнопка не защищает от двух одновременно отправленных POST. Добавлены одноразовые обязательные `batch_token`, уникальное условное ограничение БД для каждого навыка, транзакционность четырёх ответов, миграция `0008_independent_batch_idempotency.py`. Повторная отправка не создаёт новую попытку, а возвращает ошибку без частично сохранённых результатов.
- **Потеря педагогического контекста:** третье упражнение урока `a1-he-she-works` первоначально проверяло `Do you`, а должно было проверять третье лицо; исправлено на `Does Tom read books every day?`.
- **Преждевременный словарь:** в уроке чисел `tickets` заменены на уже контекстуально доступное `tea`; новая задача использует `cookies`.
- **Пунктуация:** исправлен адрес `5 Park Street`: почтовый адрес — не предложение, точка не нужна. Проверена пунктуация остальных примеров.
- **Понятность русской инструкции:** убрано противоречивое «без перевода», хотя одно из заданий специально просит передать смысл по-русски.
- **Уязвимость процедуры оценки:** добавлена проверка пропавшего исходного задания при попытке учительского вердикта. Ученик не получает автоматически уровень CEFR.

## Негативные/регрессионные проверки

- Для каждого из 28 уроков — три уникальных задачи свободного переноса, 84 ситуации в сумме.
- Подача всех четырёх ответов в одной атомарной транзакции.
- Пустой/поддельный/повторно использованный токен не создаёт новую попытку.
- Повтор в БД блокируется уникальным индексом даже при гонке.
- Искажённые задания (`accepted`/банк вариантов, повторные вопросы, неполный набор) отклоняются.
- Учитель не оценивает сохранённый ответ по неверному вопросу и не может одобрить пропавший вопрос.
- При возвращении из истории мобильного браузера кнопка повторно активна; JS выключен — HTML-форма остаётся работоспособной.
- Изменения ответа не засчитываются за измеренный уровень английского.

## Ограничения, которые не маскируем баллами

- Тесты без настоящих учеников не доказывают рост самостоятельной устной речи, аудирования или произношения.
- Проверки CSS и JavaScript без Android/TalkBack и масштабирования 200% **не доказывают** фактическую доступность.
- Тщательная редактура этих задач не заменяет профессиональную проверку всех YAML-уроков, историй, стихов, 815 вопросов и American English произношения.
- Не выполнялись нагрузочные испытания параллельных POST в реальном PostgreSQL. Ограничение на уровне БД и юнит-тесты — необходимые, но недостаточные проверки.

## Следующая независимая приёмка

1. Android Chrome 320/360/390/430 CSS px, 200% текст, TalkBack, английская/русская раскладки, горизонтальная ориентация.
2. Медленный интернет: два быстрых касания, переход в фон, возврат назад, повторный POST, появление понятных сообщений.
3. PostgreSQL: в реальных конкурентных транзакциях гарантировать уникальность одного набора и нулевую частичную запись.
4. Живые ученики: минимум 5–8 абсолютных новичков, исходная неизвестная ситуация, преподавательское оценивание без знания образца, повторная новая ситуация через неделю.
5. Проверка двенадцати и более вариаций по конкретным темам носителем/профессиональным редактором американского английского.
