# Редакционный пилот: этап 0

> Статус публикации 29 октября 2026: сохранённый пилот для ревью. После последних изменений шаблонов локальный сервер был перезапущен, но итоговая браузерная матрица и повторный LCP-прогон прервались при обновлении среды. Ниже приведены результаты завершённых более ранних браузерных проверок; они не подтверждают окончательную версию всех шаблонов. Полный Django suite запускался на итоговом коде и прошёл. Повторный быстрый прогон baseline тоже прерван, поэтому причина нестабильного теста не установлена. Перед merge нужны завершённая браузерная перепроверка и разбор теста тренажёра.
## Что сделано

Пилот включён только на **A1 / неделя 3** и **a1-cafe-order**. Иллюстрация открывает главу над заголовком. Диалог набран как пьеса: имя и ремарка, английская реплика Literata, русский перевод Golos Text. Полные формы вынесены в примечания. В уроке появились поля с пояснениями и словарь с английским словом, IPA и переводом.

На широком экране примечания открыты; на узком они раскрываются через нативный details/summary. Без JavaScript текст остаётся доступным. Примечание находится вне интерактивной аудиореплики: его раскрытие не запускает аудио.

Учебные YAML, реестры маркеров, иллюстрации, упражнения, навигация и политика движения сохранены. Новый SCSS-модуль подключён к существующему editorial-world.scss; отдельного CSS-файла или слоя не добавлено. Старое оформление educational-reading исключено только для пилотных корней, сам атрибут учебной страницы сохранён.

- Windows, Python 3.13, Django 5.2, pnpm 11.25.0, Sass 1.105.2, Chrome headless. Python использован из существующего окружения проекта; новые зависимости в него не устанавливались.

### Производительность

Пять парных локальных запусков на 1440×900, новый browser context на каждый запуск, без сетевого throttling. Медиана LCP недели: **116 → 116 мс**. Медиана урока: **104 → 120 мс**. Разница +16 мс не доказывает ни улучшение, ни отсутствие регрессии в production. Проверка production LCP: **BLOCKED**, нужен тот же deploy и одинаковый сетевой профиль до/после. [Сырые замеры](editorial-pilot/performance-comparison.json).

Четыре соответствующих теста отдельно прошли на baseline и пилоте; повторный полный прогон прошёл. Код тренажёра не менялся. Это история проверки, а не доказательство исправления конкурентности.
