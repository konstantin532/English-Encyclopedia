# Генератор фраз и модуль «Память слов» (пробная версия)

Статус: выключено по умолчанию (`EE_PHRASE_MEMORY_ENABLED=False`). Разметка признаков слов —
черновик, редактором не проверена. Числа памяти — стартовые значения из симуляции, а не измеренные
на учениках.

## Что это

- **Генератор фраз** (`apps/learning/phrase_engine/`) строит фразы из изученных слов по 22 семействам
  конструкций (be + прилагательное, There is/are, Present Simple, Past Simple, if + will …). Слова берутся
  из базы (`LexicalUnit`), признаки — из `content/phrase_engine/{nouns,verbs,adjectives,functionals,usage}.txt`.
- **Модуль памяти** (`apps/learning/memory.py`) считает рейтинг слова как вероятность вспомнить:
  `100% × 0,9^(дней с последнего ответа / прочность)`. Все числа — в `content/phrase_engine/memory.yaml`.
- **Общая проверка ответов** (`apps/learning/phrase_checker.py`) — одна на все фразы: нормализация
  регистра, пунктуации и сокращений; первая ошибка, её тип (порядок, форма, опечатка, не то слово,
  пропуск, лишнее) и слово, к которому она относится. Неуверенный диагноз не штрафует слово.
- **Тренировка** — страница `/learning/phrases/` (`apps/learning/phrase_views.py`,
  `templates/learning/phrases.html`). План дня — по рейтингу; нагрузка растёт с числом слов «пора
  повторить» (от 20 до 80 фраз).

## Данные

Отдельного журнала прогресса нет: в `UnitProgress` добавлены три поля (миграция `learning.0014`):
`memory_stability`, `memory_reviewed_at`, `memory_evidence`. Пустые поля — слово ещё не в модуле памяти.
Прежнее повторение (`stage`, `next_review_at`, `status`, счётчики) модуль **не меняет**.

Состояние текущей тренировки хранится в сессии пользователя (`request.session["phrase_practice"]`):
id задания, допустимые ответы, результат. Повтор того же POST ничего не меняет; подменённый id
игнорируется.

## Связь с уроками

При включённом флаге ответы в уроках тоже обновляют память (`UnitProgress.register`):
упражнение урока — ответ с частичной подсказкой, перевод (`record_practice`) и карточка вспоминания
(`record_recall`) — самостоятельный ответ. При выключенном флаге запись идентична прежней.

## Пилот тренажёра (#130)

Единицы `trainer_content.UNIT_UIDS` не попадают в план тренировки фраз и никогда не получают
записи памяти. Их расписание ведёт только пилот.

## Новые уровни

Позиция слова = (`Level.order`, неделя) из базы — списка уровней в коде нет. Слова A2–B2+ попадут
в модуль памяти после урока, где они введены. В генераторе слово участвует, когда для него добавлена
строка разметки; слова без разметки просто не используются в шаблонах. Для уровня можно задать свои
настройки в `memory.yaml → levels`.

## Включение и откат

- Включить: `EE_PHRASE_MEMORY_ENABLED=1`, `migrate`.
- Выключить: убрать флаг — страница отвечает 404, записи памяти не меняются, данные сохраняются.
- Откат схемы: `migrate learning 0013` удаляет три поля памяти (теряются только данные памяти).

## Известные ограничения

- Разметка признаков 835 слов A1 + A1+ — черновик; около 18% фраз в выборке грамматически верны,
  но неестественны (подробно — отчёт генератора). Редактор утверждает правила, а не каждую фразу.
- Перевода фразы на русский нет: ученик видит слова фразы с переводом и тип предложения.
- Память грамматических правил (ошибки в be, -s, some/any) пока не ведётся: такие ошибки не
  штрафуют отдельное слово.
- Рейтинг и нагрузка проверены только симуляцией; точные числа нужно подстроить на пилоте.
