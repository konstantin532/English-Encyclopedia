# Шесть бесплатных виртуальных учеников для A1

**Статус:** инструмент для редакторской проверки, не оценка людей, не браузерные роботы.
**Ветка разработки:** `situation-weeks`. **Область:** уроки 1–26 American English.

> **Обязательное предупреждение:** ИИ может предложить правдоподобные вопросы о непонятных местах, но не испытывает человеческую усталость, растерянность, страх ошибки и когнитивную перегрузку. Нельзя представлять его результаты как отзывы настоящих учеников или доказательство эффективности курса.

## Шесть разных учеников

| Имя | Роль | Что пытается обнаружить |
|---|---|---|
| Нина | Абсолютный новичок | Термины и шаги, которые учитель считает известными |
| Игорь | Буквально следует правилу | Категоричные «всегда», «только», неверные обобщения |
| Света | Теряет нить длинного объяснения | Возможную перегруженность слоя, резкие переходы |
| Максим | Учится на слух | Недостаточное пояснение звуков, сокращений и AmE |
| Лена | Привыкла повторять готовый образец | Трудности переноса из примера в новую ситуацию |
| Олег | Проверяет правила и оценку | Несогласованность YAML, интерактивных подсказок и заданий |

Это **разные роли одной модели**, а не шесть скачиваемых моделей.

## Бесплатный режим № 1 — проверка без нейросети

Из корня проекта:

```powershell
uv run python scripts/virtual_a1_students.py --mode rules --first 1 --last 26
```

Работает без API, интернета и Ollama после установки зависимостей проекта. Проверяет все 26 × 6 = **156 сочетаний** «роль × урок». Использует только эвристики: **не отвечает на задания**, не ведёт диалог и не притворяется разумным учеником. Формулировка вопросов — **гипотезы**.

## Бесплатный режим № 2 — шесть ИИ-учеников с Ollama

Однажды установите [Ollama](https://ollama.com/download) на свой Windows/Linux/macOS компьютер. Затем в терминале:

```powershell
ollama pull qwen3:4b
```

**Qwen3:4b** — подходящий стартовый вариант с возможностью отвечать по-русски; загрузка модели около 2,5 ГБ. Большая модель `qwen3:8b` около 5,2 ГБ и может потребовать больше памяти, зато обычно лучше справляется со сложными задачами. Это **размер файла модели, а не универсальное требование к RAM**. Производительность зависит от CPU, GPU и свободной памяти.

Проверка сначала **только первых двух уроков** — 12 последовательных вызовов одной модели:

```powershell
uv run python scripts/virtual_a1_students.py --mode ollama --model qwen3:4b --first 1 --last 2 --max-calls 12
```

Полная проверка всех уроков 1–26, шесть ролей на каждый урок:

```powershell
uv run python scripts/virtual_a1_students.py --mode ollama --model qwen3:4b --first 1 --last 26 --max-calls 156
```

- Ollama должна быть запущена; адрес строго локальный: `127.0.0.1:11434`.
- **Платные API, подписка, ключи доступа и облачные обращения не используются**; интернет нужен только, чтобы однажды скачать Ollama и модель. Компьютер расходует вычислительные ресурсы и электричество.
- В режиме `ollama` модель получает объяснения и условия упражнений, **но не получает поля `answer`, `accepted`, `hint_ru`, `explanation_ru` и подсказки интерактивных миссий**. Ответы сравниваются с ключом **после** попытки.
- Модель поочередно проходит уроки, ведёт краткую память по каждому из шести персонажей, задаёт до трёх конкретных вопросов на урок. У каждого вопроса обязательны **ссылка на исходный слой и проверяемая дословная цитата**. Неподтвержденные цитаты отбрасываются.
- Сравнение с ключом **не умеет** понимать все корректные перефразировки. Если ответ не совпал, он попадает на ручной разбор, а не автоматически считается ошибкой.
- Лимит `--max-calls` **по умолчанию 12**, чтобы случайный запуск не обработал сразу все 156 комбинаций. Он предохраняет компьютерное время, а не деньги.

## Выходные данные

`artifacts/virtual-students/virtual-students.md` — читаемый русскоязычный отчёт по шести ролям, урокам, источникам, вопросам и попыткам ответов.

`artifacts/virtual-students/virtual-students.json` — структурированный результат, пригодный для следующей обработки. Папка исключена из Git через `.gitignore`.

Отчёт не меняет уроки и не сливает ветки. Каждое найденное место проверяет редактор. Затем запускают `load_content`, `audit_course` и тесты. По возможности отдельные люди проходят курс без подсказок.

## Важные границы достоверности

1. **Модель читает YAML и JSON, но не кликает по браузерной странице.** Это независимый содержательный аудит, а не тест анимаций, реального аудио, мобильного отображения и работы кнопок.
2. **Модель может давать убедительный, но неверный ответ.** Подтвержденная цитата подтверждает только наличие текста, не правоту замечания.
3. **Все шесть ролей зависят от возможностей одной модели** и поэтому могут разделять её систематические ошибки. Это не шесть независимых человеческих мнений.
4. **Ученики-боты не умеют достоверно моделировать утомление и забывание.** Для измерения реальной понятности, усвоения и возвращения через неделю нужны добровольные человеческие пилоты. Руководство: `docs/pilots/a1-four-weeks/guide.md`.
5. Никакие персональные данные, результаты реальных студентов и голоса для этого инструмента не нужны.
