# Два прохода аудита 15 критериев (19 октября 2026)

Основание: main 340c60e. Ветка: audit-15-criteria-two-pass-20261019. Не выдавать автоматические проверки за оценку CEFR или реальных учеников.

## Проход 1 — подтверждённые исправления

1. Словарь отдавал много тысяч записей без пагинации; введена выдача по 48 единиц.
2. Над карточками отображалось число загруженных, а не всех найденных слов; теперь корректное полное число.
3. CEFR A1 мог выглядеть подтверждённым при verification_status=partial/pending; добавлено предупреждение.
4. Личный кабинет отдельным SQL-запросом узнавал единицы каждого урока; добавлен prefetch.
5. Вопросы одной истории имели одинаковые экранные метки поля; метки теперь содержат номер.
6. Переключение найденных фраз оставляло aria-expanded на неактивных кнопках; состояние синхронизировано.
7. После редактирования открытого ответа старый образец оставался виден; при вводе скрывается.
8. Смысловое ударение в стихах ошибочно названо ударным слогом; термин исправлен.
9. Скорость произнесения стиха преподносилась как цель; заменена на точность и естественный темп.
10. У пропусков стиха одинаковые метки; добавлен номер строки.
11. README неверно утверждал, что режим чтения есть только в 4 уроках; теперь указано 28.
12. Мобильный чек-лист ссылался на старую ветку; указан проверяемый коммит.

## Проход 2 — дополнительные исправления

1. Карта историй делала отдельные SQL-запросы по уровням; добавлено prefetch.
2. Карта могла показывать неопубликованные истории и стихи; фильтрация is_published=True.
3. Очередь повторений отдельно загружала упражнения каждой единицы; предварительная загрузка.
4. API не имел ограничителя на размер JSON сверх лимита поля ответа; добавлен предел 16 КБ.
5. CI не сообщал о фактическом отсутствии комплектов реального аудио; добавлен preflight.
6. Тестовые тоны могли выглядеть как наличие дорожки; валидатор исключает engine=test.
7. Не учитывался полный ожидаемый набор 33 аудиоманифестов A1; проверяются все.
8. Манифест мог ссылаться на несуществующий файл или выходить из static; пути проверяются.
9. Не различались синтезированная дорожка и проверенная человеком; есть список unreviewed.
10. Мутационные проверки не проверяли поведение запятой в нормализации; добавлена мутация и тест.
