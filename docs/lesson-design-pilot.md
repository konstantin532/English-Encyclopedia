# Дизайн-пилот двух уроков

База: локальный main 6e96df28908355137800d6334d5aa5d93ec16d5d. Отдельная ветка codex/lesson-design-pilot. Обновление main, публикация и rollout не входят в работу.

Цель: показать два настоящих урока как цельную учебную книгу, с приоритетом типографики. Существующие шрифты, каталог, зелёная навигация и внешний каркас сохраняются. Все тексты, семь слоёв, примеры, переводы и функции упражнений остаются.

Направление: тёплая бумага и тёмно-зелёные чернила; выразительные книжные заголовки; спокойные объяснения; английский пример и перевод составляют одну композицию. Практика выглядит как рабочая часть той же книги. Состояния кнопок различимы, тени и скругления не конкурируют с текстом. На мобильном чтение получает приоритет над вспомогательными панелями.

## Проверки риска

Остальные 58 уроков не получают stylesheet. Семь слоёв и упражнения не сокращаются. Цвета и значения грамматических маркеров не меняются. Пользовательский прогресс и исходный сервер не используются для записи. Размер текста, клавиатурный фокус, активные/disabled кнопки и переносы проверяются на пилоте.

## Исходный аудит

В браузере просмотрены фрагменты «Как работает?» всех 28 A1 и 32 A1+ на viewport 1440×900 и 390×844, первый урок дополнительно — заголовок, все семь слоёв, произношение, практика, речевая мастерская. Это выборочный просмотр фрагментов всех страниц, не полный просмотр каждого состояния всех 60 уроков.

Подтверждено: у активного «1. Понять» текст rgb(251,249,244) на фоне rgb(255,254,250); буквальные парные звёздочки вокруг обычных слов; мобильные словарь и управление предшествуют материалу. Субъективная оценка: интерфейсные карточки и насыщенная грамматическая разметка конкурируют с книжным характером текста. В текущей версии основные слои обычно разделены линиями на одной бумаге — утверждение о рамках вокруг каждого абзаца не подтверждено.

## Повторный запуск

Из корня worktree в PowerShell, если текущий предпросмотр остановлен:

```powershell
$env:PYTHONUTF8='1'
$env:PYTHONDONTWRITEBYTECODE='1'
$env:DJANGO_SETTINGS_MODULE='config.settings.local'
$env:DATABASE_URL="sqlite:///$((Get-Location).Path.Replace('\','/'))/pilot.sqlite3"
& 'F:\english-Encyclopedia\.venv\Scripts\python.exe' manage.py runserver 127.0.0.1:8001 --noreload
```

Используется уже установленный Python исходного проекта. База pilot.sqlite3 создана из seed-контента и содержит только данные локального предпросмотра, без переноса пользовательских аккаунтов. Изменения шаблонов при --noreload требуют перезапуска только этого отдельного процесса.


## Исправление глубины и оглавления, 26 октября

Только на двух страницах пилота оглавление отражает выбранную глубину. Скрытые разделы остаются в карте урока с подписью нужного режима, получают aria-disabled и исключаются из Tab-порядка. Нажатие такого пункта не меняет режим и адрес. Переходы по доступным разделам сохраняют глубину; hashchange больше не включает полный режим в пилоте. В остальных уроках прежнее поведение сохранено. Произношение, практика и мастерская доступны всегда.

Регрессионный тест сначала упал на отсутствии aria-disabled, затем прошёл. Полный JavaScript-набор: 123/123; stylesheet check: 17; git diff --check без ошибок. В браузере оба урока проверены двумя циклами трёх режимов, кликом скрытого пункта, Tab и Enter; мобильная ширина390 проверена в обоих уроках: clientWidth и scrollWidth375, навигация сохраняет режим. Подписи и клавиатурный фокус просмотрены непосредственно на снимках.

Сервер8001 восстановлен отдельным скрытым процессом Python (Start-Process), с логами pilot-server.stdout.log и pilot-server.stderr.log рядом с worktree. Старой управляемой командной сессии больше не было. Новый запуск не зависит от текущего терминального вызова, но автозапуск после перезагрузки системы не настроен.

Профильный Django-прогон после правки: 4/4 OK (включает проверку границы на всех60 опубликованных уроках). Независимый read-only обзор новой логики замечаний не обнаружил.
