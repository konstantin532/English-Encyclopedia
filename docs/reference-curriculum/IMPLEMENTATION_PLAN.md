# План эксперимента: оригинальный курс с корпусным подходом

Дата: 2026-10-16.
Исходное состояние: отдельная ветка только для **документации и методических прототипов**. Пока не менять main, situation-weeks, существующие YAML, модели и миграции.

## Этапы с контрольными точками

### 0. Discovery / compare
- Ознакомиться с `BOOK_COMPARISON_2026.md`: предварительно сопоставлены 8 изданий и выбран подход для разных учебных задач; полные страницы изданий не сравнивались и результат не объявляется научно доказанным.
- Использовать `TOPIC_DECISION_MATRIX.md` для собственной последовательности и `ORIGINAL_A1_CAFE_PILOT.md` как первый оригинальный прототип. На текущем этапе материалы **подготовлены как документы**, а не внедрены в уроки и не проверены на реальных учениках.
- Снять реальное состояние `main` и `situation-weeks` перед внедрением; изменения автора происходят параллельно.
- Проверить 14 недель A1, имеющиеся новые пакеты лексики, русские подсказки, английские тексты, CEFR-пометки и выходные умения.
- Использовать Touchstone для сверки *типов коммуникативных задач*, а не для переписывания последовательности учебника.
- Сверить грамматическое покрытие по независимому источнику, а учебные результаты — по официальным CEFR-дескрипторам.
- Подготовить матрицу: **понятие → текущая неделя → что уже есть → чего не хватает → новый оригинальный материал → проверяемый навык**.

**Gate 0:** эксперт подтвердил корректность матрицы и отсутствие копирования.

### 1. Spec
- Сохранить действующие 14 недель A1 и 16 недель A1+, не перепутать 500 и +550.
- Для концепта записать 7 вопросов, жизненную ситуацию, словарь, ограничения грамматики, ошибки новичков, фонетику AmE, рубрику контроля.
- Выстроить отдельный A1+ из уже известного A1 (спираль, не повторное начисление).

**Gate 1:** нет противоречий реестрам и авторской философии.

### 2. Original pilot
- Создать одну полностью оригинальную единицу по `SAMPLE_A1PLUS_LESSON.md` как **новый** YAML, только после проверки требуемых LX, маркеров, формы модели и сложности уровня.
- Добавить распознавание, составление, произнесение, самостоятельное высказывание и перенос в другую ситуацию.
- Подготовить audio/script, русский перевод, IPA, проверку звучания человеком.

**Gate 2:** `load_content`, `audit_course`, pytest, фонетическая проверка и независимое редакторское ревью.

### 3. Small pilot with learners
- Несколько добровольных начинающих, входная проба, выходная и отсроченная.
- Измерить понимание речи, собственное построение фраз и количество подсказок.
- Проверить доступность для тех, кто занимается **без преподавателя**.

**Gate 3:** понятные результаты, протокол ошибок и исправлений; никаких рекламных обещаний без данных.

### 4. Scale
- Применять удачный шаблон к остальным неделям; сохранять смысл истории и переход A1 → A1+.
- Дополнять регрессионные тесты на реальные ошибки и поддерживать высокий охват по содержанию, а не только по строкам кода.

## Перед любым объединением

- Сравнить изменения нового пилота с актуальными `main` и `situation-weeks`.
- Никогда не сливать прототип автоматически.
- Отдельно получить одобрение владельца на изменение действующего курса; документация в экспериментальной ветке не меняет программу ученика.

## Открытые решения для автора

1. Утвердить ли Touchstone как **методический** основной ориентир?
2. Приоритет первой реализации: улучшить одну существующую A1-неделю либо подготовить первую полноценную оригинальную A1+-неделю?
3. Допускать ли A1+ Present Continuous в начале (сейчас это черновая гипотеза, проверить с реестром и уровнем)?
4. Ввести ли будущую платную проверку учителем в пилот как необязательную услугу, не делая её частью оценки текущего обучения?

Пока решения не приняты, сохранять исходные ресурсы без изменений.
