# Решения по авторским темам, не заимствованная программа

Статус: `draft/review`. 16 октября 2026. Структура исходит из существующих недель English Encyclopedia и семи вопросов философии курса, **а не из оглавления какой-либо книги**.

## Аудит доступного учебного материала

Файлы, просмотренные на `main` (коммит `9e3f9bf54c9f` на дату проверки): `apps/curriculum/registry.py`, `content/seed_weeks/a1_w03.yaml`, `content/seed_lessons/a1_w03_l05_cafe.yaml`. Внутри `situation-weeks` уже продолжается независимый добор лексики, поэтому изменения учебного YAML без актуального сравнения веток запрещены.

| Наша тема | Что уже есть | Конкретный пробел или риск | Авторская новая учебная задача | Принцип проверки |
|---|---|---|---|---|
| Знакомство | `be`, имена, короткий диалог | Нужен самостоятельный ответ на неожиданный вопрос | Сосед не расслышал имя, ученик сам уточняет | Есть понятный ответ, уточнение, без выбора вариантов |
| Дом | `a/the`, `this/that`, предметы | «артикль = перевод» — возможное упрощение | Найти нужную вещь среди двух похожих предметов | Ученик сообщает, о каком предмете речь |
| **В кафе** | `Can I have`, `I'd like`, `want`, `Sorry?`, упражнения | **Категоричное «Give me… грубо»; важно различать контекст и тон** | Шум кофемашины: бариста неправильно расслышал два напитка | Переспросил и исправил заказ без сценария |
| Семейное фото | `who`, возраст, `his/her` | Не сделать возраст взрослого универсальным вопросом | Описать знакомого на фото, не задавая навязчивых вопросов | Рассказать понятно, не гадать о социальных нормах |
| Магазин | Цена, количество, продукты | Структура просьбы должна изменяться с товаром и количеством | Продавец принёс не тот товар, ученик уточняет | Новый предмет, самостоятельный ответ |
| День | Present Simple, время | Понимание привычки важнее механического `-s` | Два несовпадающих расписания, найти общее окно | Корректная характеристика привычки |
| Работа | `he/she works`, профессии | Не связывать каждую профессию с единственным гендером | Познакомить друга с коллегой | Принадлежность профессии и глагол, без шаблона |
| Маршрут | Предлоги, направления, просьбы | Отдельное знание слов `under` и `between` не обеспечивает навигацию | Герой потерялся около мастерской | Новая точка отправления и самопроверка |
| Телефон | `do/does`, spelling | Знание букв отдельно от понимания собеседника | Ошибка в адресе сообщения | Исправить неверную букву и подтвердить адрес |
| Свободное время | частотность, `like` | Учиться реагировать на собеседника | Обсудить планы, когда предпочтения разные | Предложить альтернативу |
| У врача | знакомые обращения | Не обещать медицинских решений из A1-лексики | Описать простое самочувствие | Корректно и понятно передать ситуацию |
| Почта | отрицания, адрес | Не путать грамматику отрицания с точностью информации | Посылку отправили не по адресу | Отрицание + нужный адрес |
| Учёба | `can`, `why/because` | `can` = умение, способность и запрос — разная функция | Объяснить, что умеешь и где нужна помощь | Ученик различает значение по контексту |
| Автобус | пересмотр A1 | Тесты могут проверять только знакомые реплики | Нужен другой маршрут, водитель отвечает неожиданно | Перенос из сцены кафе в транспорт |

## «Паспорт» каждой новой авторской темы

Обязательно заполнить перед публикацией:

- `topic_id` (собственная система, не ID главы чужого учебника).
- `learner_problem_ru`: какая реальная задача возникает у ученика?
- `can_do_ru`: что ученик сможет **сделать**, а не «знать».
- `prerequisites`: подтверждённые слова и грамматика предыдущих недель.
- `core_observation`: проверяемый лингвистический факт.
- `seven_questions`: собственные ответы на все 7 вопросов.
- `context_and_register`: где звучит естественно, нейтрально, резко и почему.
- `spoken_english`: словесное ударение, ритм, паузы, быстрый вариант, статус прослушивания.
- `interaction`: ученику нужно преобразовать фразу, а не только выбрать вариант.
- `transfer`: совершенно новая ситуация, собственный ответ, критерии.
- `source_notes`: общие справочные темы, ссылки и границы использования, без копирования фрагментов.
- `copyright_review`: подтверждение оригинальных сюжетов, реплик, заданий, порядка и текста.
- `review_status`: draft → linguistic_review → technical_review → pilot → approved.

## Матрица качества объяснения

Оценка по каждому критерию: **0** = отсутствует, **1** = частично, **2** = ясно и проверяемо; сумма 20 баллов. Не путать с оценкой самого ученика.

| Критерий (макс. 2) | Как проверять |
|---|---|
| 1. Смысл доступен с нуля | Новичок может пересказать смысл по-русски |
| 2. Термин объяснён | Нет ложной этимологии; название не заменяет сути |
| 3. Корректность грамматики | Правило не содержит ложных абсолютов |
| 4. Русско-английский контраст | Поясняет различие без буквальных кальк |
| 5. Живое американское употребление | Регистр, контекст, естественные реплики |
| 6. Звук и восприятие на слух | Понятный план фонетической проверки |
| 7. Интерактивное изменение | Ученик сам меняет элементы предложения |
| 8. Самостоятельная продукция | Ответ без вариантов и готового образца |
| 9. Перенос и повторение | Смена ситуации, отсроченный контроль |
| 10. Оригинальность и происхождение | Собственные сцены и формулировки, учёт источников |

**Порог для внутреннего редакторского ревью:** >=17/20 при обязательных 2/2 по корректности и оригинальности. Это внутреннее рабочее правило, не научно валидированная шкала и не аналог CEFR-сертификата.
