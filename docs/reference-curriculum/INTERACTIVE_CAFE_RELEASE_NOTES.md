# A1 Café Lab — первый работающий интерактивный прототип

Дата: 2026-10-16. Ветка: `experiment/touchstone-inspired-curriculum`. Путь в приложении: `/lab/cafe/`.

Статус: **interactive beta**. Это новая самостоятельная учебная страница рядом с действующим A1, а не замена уже опубликованного урока и не готовый утверждённый модуль курса. Конфликты с добором новых единиц в `situation-weeks` предотвращаются тем, что исходный YAML и LX не менялись.

## Что реализовано

1. **Услышать:** шесть авторских реплик Мии и Тома. Системная озвучка доступна только при наличии локального голоса `en-US` через Web Speech API; это *не* проверенная записанная американская речь и не гарантируется в разных браузерах. Текст и русский смысл раскрываются по требованию.
2. **Исследовать:** 8 интерактивных элементов слова с действующими маркерами `T8 / D7 / D3 / N1 / S3 / O8`. Нажатие показывает контекст, а раскрывающиеся объяснения рассказывают об употреблении и русско-английском различии.
3. **Построить:** 1–3 порции tea/coffee; `I'd like…` или `Can I have…?`. Автоматически обновляются число, существительное в множественном числе, английская фраза и русский перевод.
4. **Проверить понимание:** мини-задание «что Мия услышала?» с ясной обратной связью и повторной попыткой.
5. **Ответить самостоятельно:** свободный текст для исправления заказа; образец показывается **только после отправки**.
6. **Попрактиковать речь:** необязательная запись через `MediaRecorder`; микрофон запрашивается строго по кнопке. Голос остаётся локально в памяти страницы, серверу не отправляется; запись можно прослушать и потерять при закрытии вкладки.
7. **Перенести навык:** исправить ошибочное количество печенья без исходного ответа на экране; самооценка по смысловым критериям.

## Что сознательно ещё НЕ сделано

- Настоящая озвучка Kokoro/студийный голос в вариантах очень медленно / медленно / естественно; роли пока не озвучиваются разными голосами.
- Точная проверка произношения и акустическая оценка. Кнопка записи — **прослушивание себя**, а не автопроверка.
- Надёжная автоматическая оценка произвольных свободных реплик: ученик видит образец и рубрику, но система **не заявляет**, что любой правильный ответ распознан и оценён.
- Сохранение прогресса, интервальное повторение, работа офлайн и преподавательская проверка записей. Лаборатория не записывает попытки на сервер.
- Утверждение CEFR всех использованных единиц, редакторское подтверждение естественности, доступность на реальных смартфонах и пилот на людях.
- Перенос новой сцены в семантически проверенный `content/seed_lessons/`. Для этого необходимы отдельные LX/валидатор/A1-контроль.

## Проверки

Автотест Django: страница для гостя; все 6 секций; ссылки; доступность из урока недели 3; отсутствие ссылки у другого урока; `POST` запрещён.

Автотест Node: 1/2/3 порции; `tea/teas`; `coffee/coffees`; две вежливые конструкции; корректное русское количество; отказ от неверного ввода; распознавание ответа на вопрос по смыслу; выбор только `en-US` голоса; целостность диалога.

**CI**: `uv run python manage.py check`, `uv run python manage.py makemigrations --check --dry-run`, `uv run pytest -q`, `node --test tests/js/audio-player.test.cjs tests/js/cafe-lab.test.cjs`, `load_content`, `audit_course`.

Контроль вручную после получения результатов CI:
1. Запустить `uv sync && uv run python manage.py migrate && uv run python manage.py load_content && uv run python manage.py runserver`.
2. Открыть `http://127.0.0.1:8000/lab/cafe/` и страницу `http://127.0.0.1:8000/lessons/a1-cafe-order/`.
3. Проверить на 390px и 1280px, клавиатуру, фокус, экранный диктор, `prefers-reduced-motion`.
4. Проверить работу без разрешения микрофона и без голоса `en-US` — должны оставаться доступными все текстовые задания.
5. Проверить сцену, варианты множественного числа, что образцы свободных ответов не видны **до** первой отправки в интерфейсе (хотя присутствуют в исходном HTML).
6. Провести независимый лингвистический разбор и пользовательский пилот, **не объявлять проверку выполненной без реального запуска**.

## Авторское право

Общие факты о лексике и вежливых просьбах проверены на общеупотребительном материале; диалог и упражнения написаны специально для Anna/Tom/Mia и не переводят страницу или композицию любого выбранного учебника. До публикации требуется завершающая редакторская проверка.
