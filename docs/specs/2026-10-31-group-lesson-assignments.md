# Спецификация: назначения уроков группам

**Первая версия. Реализация идёт отдельными этапами; эта спецификация — источник требований.**

## Цель и границы

Учитель назначает опубликованный урок своей группе. Ученик видит задание и статус, но сохраняет самостоятельный маршрут. Учитель видит работы, ожидающие проверки, и просроченные задания. Рейтинг, чат, напоминания и автоматический вывод об уровне знаний не входят в первую версию.

## Правила задания

- При создании назначения фиксируется состав группы. Позднее вступившие ученики автоматически его не получают.
- Повторное назначение того же урока создаёт новую запись назначения и отдельный прогресс каждого участника. Старые статусы и сроки не перезаписываются; незавершённое старое задание остаётся активным и может просрочиться. Карточки различаются датой назначения и сроком.
- Каждый ответ, отправленный из конкретного назначения, связывается с отдельной записью ученика для этого назначения. Не определять связь по совпадению урока, ученика или даты. Ответы из самостоятельного маршрута остаются без назначения.
- **Начало:** первое открытие урока после выдачи назначения.
- **Завершение:** явное нажатие «Отметить урок пройденным» в конце основной части. Дополнительная практика необязательна; завершение — самоотчёт, а не подтверждение владения материалом.
- **Прошёл раньше:** весь урок до назначения не сохраняется как отдельное событие (`templates/lessons/detail.html:102-105`). Старые `ExerciseAttempt` и `UnitProgress` не доказывают прохождение целиком. Ученик может выбрать «Я уже проходил этот урок»; это сохраняется как отдельная самоотметка и не считается проверкой учителя.
- **Срок:** необязательная дата в часовом поясе `Europe/Moscow` (`config/settings/base.py:137-139`). Просрочка начинается в 00:00 следующего дня, если задание не завершено и не отмечено как пройденное раньше. Без срока просрочки нет. Завершённое задание не просрочивается из-за ожидающего проверки ответа.
- **Выход или переход в другую группу:** незавершённые назначения становятся «Снято после выхода» и исключаются из просрочки. Завершённые остаются завершёнными. Записи и ответы не удаляются: ученик видит историю, но обычный прежний и новый учителя не видят ответы после выхода; новая группа ничего не наследует. Назначение доступно ученику только для чтения; повторное вступление его не возобновляет. Учитель может создать новое назначение.
- Уже сохранённый отзыв остаётся у ученика. В первой версии непроверенный ответ после выхода остаётся в истории ученика, но не передаётся учителю новой группы и исчезает из очереди обычного прежнего учителя. Существующее явное разрешение `teacher_sees_all` сохраняет прежнее поведение.

Проверка свободного ответа — отдельна от прохождения урока. Учительский отзыв остаётся привязан к точному `IndependentAttempt` (`apps/learning/models.py`, `apps/teaching/review.py`). Учебная проверка с ответом без вариантов сейчас есть для уроков A1; для других уровней первая версия показывает прохождение и срок, но не создаёт новую работу для ручной проверки.

## Список учителя «Требуют внимания»

1. **Ожидает проверки:** ученик, урок, время, конкретный ответ и действие «Проверить эту работу». Использовать существующие условия очереди: исход `NEEDS_REVIEW` или `SELF_REPORTED`, вердикт ещё не сохранён. Совпадение с образцом само по себе не отправляет ответ на ручную проверку.
2. **Просрочено:** ученик, урок, срок и состояние «не начато» или «в работе»; действие ведёт к назначению и прогрессу ученика. Не начатое задание до срока не считается требующим внимания.

Работа в ожидании проверки и завершение назначения имеют независимые статусы.

## Данные и экраны

- `LessonAssignment`: группа, опубликованный урок, назначивший учитель, время создания и необязательный срок.
- Запись прогресса ученика на каждое назначение: назначение, ученик из состава группы на дату создания, статус, время начала/завершения, источник завершения, время снятия после выхода. Пара «назначение + ученик» уникальна; один урок может иметь много назначений.
- Необязательная связь `IndependentAttempt` с точной записью прогресса назначения. Старые ответы остаются без связи; заключения, критерии и отзывы не дублируются.
- **Ученик:** карточки назначений со сроком, статусом и действиями «Начать/продолжить» и «Уже проходил»; в конце урока — сохранение завершения. Обычный маршрут, повторение и выбор следующего урока остаются доступны (`templates/learning/dashboard.html`).
- **Учитель:** назначение опубликованного урока своей группе; список участников/статусов; отдельные строки повторных назначений; список ожидающих проверки ответов и просроченных назначений. Проверку ответа выполнять на существующем экране (`templates/teaching/review_detail.html`).

## Доступ и тесты

- Создавать назначение можно только для собственной группы и опубликованного урока. Все чтения и изменения проверяют права на сервере.
- Ученик работает только со своими назначениями и ответами. Обычный учитель видит только текущих учеников своей группы (`visible_students`); прямой URL и подмена ID не расширяют доступ. Явное глобальное право владельца/`teacher_sees_all` остаётся без изменений.
- Тесты:
  - одно занятие назначено группе дважды: создаются разные назначения, статусы и сроки не смешиваются;
  - ответы из каждого назначения связаны с его собственной записью прогресса; самостоятельные ответы не прикрепляются автоматически; отзыв на одном ответе не меняет другой;
  - назначение без срока никогда не становится просроченным;
  - в день срока незавершённое назначение ещё не просрочено; оно просрочено с 00:00 следующего дня по `Europe/Moscow`;
  - явная отметка «Уже проходил» создаёт отдельное состояние, не присваивается автоматически по частичным старым попыткам и исключает задание из просрочки;
  - ученик, вступивший в группу после назначения, не получает старое назначение;
  - выход/смена группы снимает незавершённые задания и исключает их из просрочки; завершённые сохраняются;
  - после выхода ученик видит историю и ранее полученный отзыв; обычные прежний и новый учителя не видят непроверенные ответы; попытки изменить данные по чужим ID отвергаются;
  - сохранить существующее поведение для явно выданного `teacher_sees_all`;
  - самостоятельное обучение, очередь ревью и старые ответы сохраняются; миграция не меняет исторические записи.
- Добавить сценарии, например, в `tests/test_teaching_assignments.py`; расширить `tests/test_teaching.py`, `tests/test_teacher_review.py` и `tests/test_a1_teacher_review.py`. Проверить мобильный экран и управление с клавиатуры.

## Пять этапов реализации

1. **Данные:** модели назначения и прогресса участника; уникальность пары «назначение + ученик»; необязательная привязка ответа. Миграция оставляет старые попытки без назначения.
2. **Правила и доступ:** снимок состава группы, повторные назначения, сроки, начало/завершение, отметка «Уже проходил», снятие незавершённых заданий при выходе или смене группы и точная привязка ответов.
3. **Кабинет ученика:** карточки и статусы назначений, начало/продолжение и отметка завершения. Самостоятельный маршрут работает и без назначений.
4. **Кабинет учителя:** назначение урока своей группе, статусы участников и список требующих внимания; переиспользовать текущую проверку ответов.
5. **Проверка целиком:** профильные тесты по ходу работы; полный набор один раз в конце; проверка миграций, прав между группами, экранов на 390 px и с клавиатуры.

Команды этапа проверки: `uv run python manage.py test tests.test_teaching_assignments tests.test_teaching tests.test_teacher_review tests.test_a1_teacher_review`; полный набор в конце: `uv run python manage.py test tests --parallel auto`; также `uv run python manage.py makemigrations --check --dry-run`, `uv run python manage.py check`, а для экранов — `pnpm check:css`, `pnpm test:ui` и визуальная приёмка.
