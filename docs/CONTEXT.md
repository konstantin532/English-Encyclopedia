# Словарь проекта English Encyclopedia

Термины, которыми пользуются код, контент и обсуждения. Если слово в коде расходится со словарём, правится код.

**Учебная единица (LexicalUnit)** — одно конкретное значение слова или выражения с постоянным ID `LX-00001`. Одна форма с двумя значениями даёт две единицы. Формы слова (books, houses) новыми единицами не считаются. Квота курса — ровно 6200 единиц.

**Учебная категория (PartOfSpeech)** — одна из 11 групп визуальной схемы: NOUNS, VERBS, ADJECTIVES, ADVERBS, NUMERALS, DETERMINERS, PREPOSITIONS, PARTICLES, CONJUNCTIONS, INTERJECTIONS, DISCOURSE. Это учебная схема, а не утверждение лингвистики, что частей речи ровно 11.

**Маркер** — тип линии, закреплённый за категорией навсегда. Снизу — знаменательные слова, сверху — служебные, точечное зачёркивание — дискурс.

**Слитная форма** — каждая часть получает свой маркер: `[T8]I[/][D1]'m[/]`, `[D1]is[/][X1]n't[/]`, `[D1]do[/][X1]n't[/]`, `[D7]ca[/][X1]n't[/]`.

**Класс (SemanticClass)** — тематическая группа внутри категории, ID вида `S3`. От 1 до 10 на категорию.

**Цвет класса** — цвет палитры с тем же номером, что и класс. Отдельно не хранится, поэтому класс не может получить два цвета.

**Уровень курса (Level)** — A1, A1+, A2, A2+, B1, B1+, B2, B2+. Внутренняя шкала курса. Уровень CEFR слова хранится отдельно.

**CEFR единицы** — уровень конкретного значения по Oxford 3000/5000 и English Vocabulary Profile. Пока сверки не было, стоит `unverified` («CEFR: требует проверки»).

**Пакет** — порция контента, создаваемая и проверяемая целиком: например, «A1 → NOUNS, неделя 1».

**Слой** — один из семи шагов объяснения темы: Что это → Почему так называется → Как работает → Почему именно так → Как говорят американцы → Исключения → Попробуйте сами.

**Упражнение (Exercise)** — задание одной из ступеней: узнавание, подстановка, производство, перенос.

**Статус единицы у ученика** — `new → recognition → guided_use → independent_use → active`, плюс `review_due`. В `active` единица попадает только после правильного употребления в трёх разных конструкциях.

**Интервалы повторения** — 0, 1, 3, 7, 14 дней.

**Аудит** — автоматическая проверка курса (`audit_course`) по разделу 21 мастер-промпта.

**Сцена недели (WeekScene)** — цель, диалог с репликами героев, 5–8 готовых фраз и задание в жизнь; один к одному с учебной неделей. Ситуация и грамматика задаются планом недели, контент — в seed_weeks.

**Сфера (sphere)** — одна из 12 областей жизни из SPHERES: знакомства, дом, еда и другие. Возвращается на следующих уровнях с более сложным материалом.

**Скороговорка (TongueTwister)** — короткая тренировка произношения недели; номер равен номеру недели во всём курсе (1–150). Серии: трудные звуки, сокращения, слияния, быстрая речь. На A1 только знакомые слова и 3–8 слов.

**Цель недели (WeekGoal)** — личная отметка ученика «Получилось» (done) или «Ещё нет» (not_yet) по цели «Я смогу…». У одного ученика одна текущая отметка на неделю.

**Живая речь (spoken)** — разговорный вариант реплики рядом с полной формой text; естественный темп озвучивается по нему. Обычные сокращения начинаются на A1, слияния — на A2+. «Как сокращают» в уроке хранится в Lesson.contractions.

**Рамка истории (story_beat)** — необязательная русская рамка сцены недели: intro_ru (вступление над диалогом), outcome_ru (что случилось, в блоке «Чем всё закончилось») и next_hook_ru (зацепка). Рамка не вводит улик, которых нет в английских репликах, и не влияет на доступ к следующей неделе.

**Контрольная проба** — разговор из docs/pilots/a1-four-weeks/assessment.yaml для ведущего: недельные w01…w04 и параллельные формы pre/post/delayed. Только слова, известные к max_week; в базу не загружается; озвучивается в static/audio/pilot-a1/.
