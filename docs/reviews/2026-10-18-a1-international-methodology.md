## 2. Сопоставление с тем, что уже есть в репозитории

Источники проекта: `content/seed_lessons/a1_w*_l*.yaml`, `content/active_a1/topics_*.json`, `templates/lessons/detail.html`, `templates/components/drill.html`, `apps/taxonomy/markup.py`, `docs/pilots/a1-four-weeks/guide.md`.

### Сильные стороны, которые стоит **сохранить**

1. **Семь слоёв** и необычно подробное объяснение «почему так»: ценность для русскоязычных с A0. Не обрезать содержание целиком ради короткого интерфейса.
2. **Интерактивные миссии и перенос**: у уроков A1 уже есть шесть контекстных миссий и задания на применение; они **не отсутствуют**, задача — сделать их оценку надёжнее.
3. **Американская фонетика и речевые примеры** предусмотрены; синтез аудио/реальное звучание требуют отдельной проверки, нельзя путать наличие IPA с качественным слушанием.
4. **Истории, стихи и скороговорки** существуют. Их следует связать с конкретными *звуковыми/речевыми* целями, а не добавлять случайный текст.
5. **Учёт прогресса и повторение** уже реализованы в обычных упражнениях для зарегистрированных пользователей. Не писать «повторов нет»; проверить перенос достижений между дополнительной практикой и основным курсом.
6. **Пилот pre/post/delayed** на 4 недели уже спроектирован; не объявлять его проведённым без настоящих данных.

## 3. Как должен выглядеть *один* действительно сильный урок

Пример авторского сценария для A1 — урок 5, **в кафе**. Это наша оригинальная концепция, не пересказ книги:

1. **Ситуация без правила.** Бариста спрашивает: *What would you like?*; ученик должен понять цель разговора.
2. **Одна ясная пара.** *I like tea* — «мне нравится чай вообще»; *I'd like tea, please* — просьба об одном заказе. Кнопки «предпочтение / заказ».
3. **Прогноз до объяснения.** В новой ситуации «Что скажешь, чтобы получить чай?» ученик выбирает/строит реплику. **Ключ скрыт**, пока не нажмёт «Показать разбор».
4. **Разбор работы каждого слова.** *I / would / like / tea / please* с уже существующей визуальной разметкой; почему *I'd*, почему *please*, почему *want* не обязательно грубо.
5. **Звук.** Два оригинальных примера AmE с различиями ударения, пауз и сокращения; не имитировать аудио при отсутствии файла.
6. **Смена ситуации.** Бариста не расслышал напиток; ученик должен **исправить ошибку** в заказе без копирования примера.
7. **Вспоминание.** Через интервал — новый заказ, ещё один контекст; отметка «сам / с подсказкой / не удалось». Не оценивать свободную реплику только буквальным совпадением.

Та же структура может применяться к *this/that, is/are, do/does, can/can't, near/next to, why/because*. Полную лингвистическую справку сохраняем отдельно, она доступна заинтересованному ученику.

## 4. Независимый критерий эффективности: не «сколько ответов угадал»

ACTFL 2024 определяет навыки в терминах реальных коммуникативных задач, а не только знания правил: https://www.actfl.org/proficiency-guidelines-overview. А рекомендации NCSSFL–ACTFL 2026 прямо указывают, что единичное выполнение задания **не** доказывает устойчивое умение: https://www.actfl.org/educator-resources/ncssfl-actfl-can-do-statements. Последние материалы имеют условия образовательного/некоммерческого использования: **не копировать их шкалы в коммерческую платформу без разрешения**.

Обоснованная **собственная** рубрика для проб A1:

- **Понял:** без перевода узнаёт цель короткого высказывания.
- **Выбрал:** различает две близкие конструкции в новой ситуации.
- **Составил:** сам собрал фразу, не заглядывая в ответ.
- **Исправил:** если его не поняли, смог переспросить или заменить слово.
- **Перенёс:** использовал тот же принцип с другими известными словами.
- **Удержал:** спустя интервал смог повторить действие без непосредственной подсказки.

Считать эти признаки отдельно, не превращать автоматически в «сертифицированный A1». Исследования L2 показывают пользу извлечения из памяти и интервального повторения, но не дают универсального расписания, подходящего всем: https://www.cambridge.org/core/journals/studies-in-second-language-acquisition/article/review-of-laboratory-studies-of-adult-second-language-vocabulary-training/18F0A5D1FFC829CE05931B2EEE83124A/share/9612bae4e131a6e3d9d0b0aacac044f5587eb6e0.

## 5. Порядок внедрения без ломки платформы

**Этап I (выполнен):** закрытый «Показать разбор» в диагностике 1–26, автоматические проверки безопасности рендера и сохранения остальных блоков.

**Этап II:** 3 экспериментальных урока №3, 5, 17: разная подача одного правила, визуальные пары, скрытый ключ, перенос без подсказки. **Не внедрять одновременно на все 26**, пока не проверен UX.

**Этап III:** оригинальные ритмические речевые микросцены №5, 18, 22; отдельно слушание AmE с собственным лицензированным аудио и проверкой фонетики.

**Этап IV:** синхронизация `content/active_a1/` через общий concept ID, затем автоматические проверки рассогласований, затем настоящие пилоты и отсроченные пробы.

**Запрет:** скачивать чужие PDF, копировать страницы, переводить авторские упражнения и «маскировать» их под свои — нельзя. Оригинальность и точность важнее количества позаимствованных учебников.
