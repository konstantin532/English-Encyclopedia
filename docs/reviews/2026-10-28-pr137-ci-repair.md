Ветка: `codex/beginner-changes-review-20261028`. Исходный коммит: `18b86ca72296b751248d3c6ad81fbf7c910bd843`.

## Подтверждённые причины

- Общий быстрый прогон воспроизвёл исходные `127 failures, 2 errors`: `Ran 1081 tests in 196.966s`.
- Гостевой fixture повторно создавал уже загруженные уроки: `UNIQUE constraint failed: lessons_lesson.slug`.
- Историческая модель пользователя не знает нового поля; при вставке в новую схему без постоянного SQL default возникал `NOT NULL constraint failed: accounts_user.markers_enabled`.
- `hesitant` уже есть в манифесте голосов; строгий список допустимых эмоций в тесте отставал от него.
- Atlas пытался снять скриншот скрытой речевой мастерской и раскрыть удалённую лестницу. Отдельно старая геометрия главной перестала соответствовать новым подписям.
- В скачанном артефакте исходного GitHub job Coverage: `92.06033308892846%`, 1147 testcase и 28 упавших testcase. Сам coverage ratchet проходит; job останавливается на тестах. Порог покрытия `90%` и минимум `131` testcase не изменялись.
- SQL default устанавливается новой accounts `0003_markers_enabled_db_default`, поэтому обновление работает и для уже применённой старой `0002`. Исходная `0002` сохранена.
