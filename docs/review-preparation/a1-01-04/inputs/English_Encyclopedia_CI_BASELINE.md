## Что означают эти результаты

Технический CI проходит, но зафиксированы незакрытые показатели содержания. Они не равны автоматически ошибочной грамматике или неуспеху ученика.
547 вместо 550 — расхождение с заявленной численностью, а не разрешение дописать три случайных слова.
44% — результат алгоритма повторения; перед изменениями следует проверить его правила подсчёта, формы и фразы.
Длинные истории — повод для методической рецензии, не основание механически обрезать сюжет.
Неподтверждённый CEFR — отсутствие достаточной проверки, а не доказательство неправильного уровня каждой единицы.

Числовые exit codes отдельных CI-команд API не предоставил. Зафиксированы `success` и строки результата; код 0 не выдумывается.
