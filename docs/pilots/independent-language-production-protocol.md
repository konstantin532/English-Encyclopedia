# Протокол: самостоятельное владение A1 без подсказок (пилот)

**Состояние:** методика исследования, **не** результаты исследования. Банк проверочных сцен и ключи **не размещать в публичном репозитории**. До набора участников согласовать правила обработки данных и получить необходимые согласия.

## 1. Задача и границы A1

Проверить, способен ли обучающийся **из памяти** понять короткую реплику, выбрать знакомое слово, создать простое новое предложение, задать вопрос и решить повседневную задачу на лексике, введённой **до момента проверки**. Не требовать беглости или полноценного A2. Сопоставлять цели с дескрипторами CEFR A1; не выдавать собственный тест за официальный сертификат.

Главное различие: узнавание готового ответа, написание под сильную подсказку, новизна ситуации и самостоятельная речь — разные способности.

## 2. Объект проверки

Первый пилот: недели 1–4 A1, 8 уроков; существующий материал `docs/pilots/a1-four-weeks/assessment.yaml` — только один из источников. После пилота расширить по методически сгруппированным темам до всех 28 уроков. Не считать 28 уроков автоматически валидированными после проверки первых восьми.

## 3. Набор и группы

Ориентир для исследовательского пилота: **12–24 добровольца**, начинающих A0/A1, с фиксированным временем занятий; это удобная гипотеза для поиска крупных проблем, а **не** достаточная мощность для уверенного доказательства превосходства. При возможности рандомизировать участников по исходному уровню в две группы: English Encyclopedia и сопоставимое по времени обучение тем же навыкам другим способом. Если нет контрольной группы, показывать только внутриличностные изменения, не причинный эффект платформы.

Для несовершеннолетних — необходимые разрешения законного представителя и соответствующие правила защиты данных. Использовать вымышленные имена в языковых заданиях; не записывать реальные адреса, диагнозы, номера телефонов и другие личные данные.

## 4. Формы и моменты

| Этап | Когда | Назначение | Правило |
| --- | --- | --- | --- |
| PRE | До первого урока | исходные навыки | форма A; никто не видел ответы |
| POST | после последнего урока пилота | непосредственный эффект | параллельная форма B; никаких подсказок |
| D7 | через 7 дней | сохранение и новый перенос | форма C; не копировать PRE/POST |
| D30 | через 30 дней | долгосрочное сохранение | форма D; отдельные темы; отсутствие как missing |
 
**Не подменять задержанный тест просто повторным показом тех же фраз.** Вести журнал дополнительной практики между замерами; пропуски указывать отдельно. Если человек явился на 20-й день, это не D7.

Для итогового 28-урочного курса расширить бланк и заранее сбалансировать трудность параллельных форм; без калибровки равная длина не означает равную трудность.

## 5. Структура каждой формы

Для первой проверки 1–4 недели предложить 12 заданий с разными глаголами/именами/числами, полностью на знакомом материале:

1. **2 × словарное извлечение:** русская подсказка или изображение → вспомнить слово без банка.
2. **3 × самостоятельное предложение:** RU коммуникативная цель → новая английская фраза без образца.
3. **2 × преобразование:** вопрос / отрицание / замена предмета с сохранением смысла.
4. **2 × аудирование:** короткая новая запись голосом; определить информацию, без печатного английского текста.
5. **2 × интерактивное общение:** собеседник меняет доступность товара или количество; ученик должен уточнить/исправить.
6. **1 × новая ситуация:** одновременно применить два изученных навыка, например вежливую просьбу и исправление недоразумения.

**Письмо и речь оценивать отдельно**: 12 пунктов — пакет заданий, устные упражнения имеют собственную шкалу. Не использовать реплики сайта дословно. Цель задания не должна включать правильную английскую фразу. Избегать слов, ещё не введённых к этой неделе.

Для проверки 28 уроков использовать стратифицированную выборку (знакомство, дом, кафе, семья, магазины, рутина, работа, город, сообщения, хобби, здоровье, почта, учёба, транспорт), а не полагаться только на последнюю страницу A1.

## 6. Процедура

Перед попыткой записать, использовал ли ученик помощь: **без помощи / конспект / переводчик** (самоотчёт). В независимой части никаких видимых вариантов, модельных фраз, подсказок после неверной попытки и автоподстановок. Ответ должен быть первоначальным; фиксировать время, попытки и отказ от задания. После сдачи допускается учебная обратная связь, но она не изменяет исходную оценку.

Предусмотреть разумные условия доступности: клавиатура, экранный диктор, удобное время для формулировки и отсутствие наказания за типографские варианты.

## 7. Рубрика слепого оценивания

Два независимых проверяющих, которые не знают форму и группу/время ответа, оценивают по критериям:

| Ось | 0 | 1 | 2 |
| --- | --- | --- | --- |
| Смысл | не передан / противоположен | передан частично | вся обязательная мысль передана |
| Языковая форма | мешает пониманию | ошибки, но понятно на A1 | ясная форма уровня A1 |
| Коммуникативное действие | цель не достигнута | частично | цель достигнута |

**Основной строгий исход:** без помощи, смысл=2, коммуникативное действие=2; форма не должна препятствовать пониманию (>=1). Ошибки, допустимые в A1, не автоматически обнуляют коммуникативный успех. В многочастных заданиях каждая обязательная мысль должна присутствовать; "Я из России" не заменяет "Я из России и говорю по-английски".

Двойная слепая разметка минимум **20%** материалов; конфликтные случаи рассматриваются отдельно, с сохранением исходных оценок. Рассчитать согласие (например, взвешенная `κ` для упорядоченной 0/1/2 рубрики), не выдумывать его.

## 8. Метрики: определить до сбора ответов

- **IPR:** самостоятельных выполненных по рубрике задач / всех назначенных независимых задач; отдельно reported completion и assisted share.
- **NTR:** достигнутых целей в новых ситуациях / назначенных новых ситуаций; для каждого типа ситуации отчитываться отдельно.
- **D7 / D30:** доля подтверждённых независимых успехов среди всех назначенных задач по фиксированной волне, отдельно анализ только явившихся и процент missing.
- **CTS:** успехов в коммуникативных задачах / всех назначенных коммуникативных задач; исходный и delayed отдельно.
- **FPR:** автоматических "верно" при человеческом "не достигнуто" / всех автоматических "верно" (также дополнительно доля среди всех истинно неверных; ясно указывать знаменатель).
- **FNR:** автоматических "неверно" при человеческом "достигнуто" / всех автоматических "неверно" (также дополнительно доля среди истинно правильных).
- **Help Dependence:** задач, выполненных с заявленной помощью / всех выполненных задач; помощь **не** засчитывать в основной IPR.

Незаполненные задания учитывать как незавершённые в первичном отчёте; статистическую неопределённость показывать явно (число участников, знаменатель, доверительные интервалы, характер неслучайных пропусков). Не объединять в одну оценку A1 письменные и устные результаты без отдельной обоснованной шкалы.

## 9. Независимые A/B/C/D задания и безопасность банка

Непубличный банк хранить у исследователя с доступом только оценщикам. Для открытого GitHub публиковать **только протокол**, рубрики и статистические результаты без ключей и персональных ответов. Ни одна модель/агент не должен создавать вымышленные "прохождения" реальных учеников или фиктивные проценты.

Внутренний формат записи: `participant_pseudonym, wave, form, task_id, skill, response_channel, first_response, assistance, blind_rater_id, meaning_0_2, form_0_2, task_0_2, timestamp_utc, missing_reason`. Поля с персональной информацией, полученные нечаянно, не хранить без отдельного обоснования; сырые ответы минимизировать.

## 10. Шесть диагностических профилей ИИ, но не шесть учеников

Для технического тестирования подать на сайт контролируемые входные ответы:
1. нулевой ответ / незнание слова;
2. буквальное заучивание старой фразы;
3. неверный порядок слов;
4. корректный синоним, отсутствующий в `accepted`;
5. полное понимание русского смысла и слабое письмо;
6. "обход" многочастного задания, например ответ только на первую половину.

Отчёт содержит конкретный `POST`, статус HTTP, JSON/HTML, запись БД и ожидаемое решение человека. Не приписывать виртуальным профилям память, устную способность или реальный прогресс.

## 11. Критерии принятия изменений

Перед добавлением новой педагогической функции предъявить (а) выявленный разрыв, (б) тест/наблюдение, (в) механизм, (г) тест на побочные эффекты, (д) сравнительный результат по заранее объявленным метрикам.

При отсутствии реальных участников достоверный вердикт только: "инструменты для испытания подготовлены; эффективность пока не измерена". Новая страница тренажёра или 100% CI сама по себе не повышает эмпирическую образовательную эффективность.
