# Полный дизайн атласа

База: `5ce8dec72bb3b0f6b9e8ce779e11d6580bba8b41`, ветка `design/complete-atlas`. **Сливать после #164.** Автор выбрал: «Выбери сам лучший вариант для моего курса». Направление — существующий DESIGN.md, развитый на весь продукт.

## Образ и пять решений
1. Задача: учиться, читать и понимать следующий шаг; учителю — работать с назначениями и ответами.
2. Отличительный образ: иллюстрированный книжный атлас американской жизни, с настоящими героями курса.
3. Шрифт: Literata для заголовков и английских образцов, Golos Text для управления и русского объяснения, Gentium Plus для IPA.
4. Компоновка: общая спокойная оболочка; широкие каталоги, узкое чтение с полями, плотные рабочие списки. Карточки различаются по смыслу объекта.
5. Движение: обратная связь действия; сохранять читаемость без JS и режим уменьшенного движения. Не добавлять массовое появление блоков.

## Проверяемые роли каждой семьи
Оболочка и идентичность; заголовок и вводный текст; основное действие; навигация внутри раздела; содержимое; дополнительная справка; поля/ошибки; пустое состояние; активный/disabled/focus; мобильный порядок и reduced motion.

## Неизменяемые контракты
Имена маршрутов, CSRF, разрешения, data-атрибуты JS, учебная разметка `.mk`, содержание курса и данные. Не скрывать обязательные сведения о CEFR/самооценке. Не заменять отсутствующий результат выдуманным. Локальная приёмка использует отдельную SQLite с синтетическими пользователями.
