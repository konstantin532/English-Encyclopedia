# English Encyclopedia — правила для агентов

- Общение с автором — на простом русском.
- Создание и редактура уроков — по [доказательному чек-листу](docs/lesson-review.md), без обязательного расширения каждого блока; существующие предметные правила и разрешения сохраняются.
- Реестры `apps/taxonomy/registry.py` и `apps/curriculum/registry.py` — источник истины. Не менять смысл занятых ID классов, маркеров и цветов.
- Новая лексика — только YAML-пакетами в `content/seed_lexicon/` с новыми ID `LX-xxxxx`. Не выдумывать подтверждение CEFR: без сверки ставить `cefr: unverified`.
- После изменений контента: `load_content`, `audit_course`, тесты.
- Тесты: во время работы — быстрый прогон `uv run python manage.py test tests --exclude-tag slow --parallel auto` (или только файл с тестами изменённой части); перед завершением шага и перед слиянием — полный `uv run python manage.py test tests --parallel auto`. Курс грузится в тестовую базу один раз (`tests/runner.py`): в `setUpTestData` звать `ensure_content()`, а не `load_content`. Тест, который ломает или перезагружает весь курс, помечать `@tag("slow")`.
- Перед завершением работы — проверка страниц в браузере.
- Общий протокол работы, Git и проверок — [AGENTS.md](AGENTS.md); он обязателен и для Claude. При расхождении с этим файлом сообщи автору.
- Скиллы проекта лежат в `.agents/skills/` (общие для Claude и Codex); копии в `.claude/skills/` совпадают с ними, это проверяет `tests/test_agent_setup.py`. Перед работой с интерфейсом прочитать [DESIGN.md](DESIGN.md) и навык `encyclopedia-design`. Перед любой новой или перерисованной картинкой (обложки, портреты, иллюстрации) прочитать `.agents/skills/ee-illustration/SKILL.md`.
- Русская транскрипция строится автоматически из IPA (`apps/lexicon/phonetics.py`, одна таблица на весь курс). Ручной вариант — поле `ipa_ru` у слова или ключ `ru` в `sound_notes` и `pronunciation` стихов. Новый символ IPA добавлять в таблицу, а не обходить вручную.

- При работе с неделями читать спецификацию, план и журнал docs/{specs,plans}/2026-10-14-situation-weeks*.md; записывать решения и проверки в журнал. Контент недель — content/seed_weeks/*.yaml, план — content/manifests/weeks_plan.yaml.
- Диалог использует только лексику, известную к своей неделе. Готовые фразы — unit_type: phrase; слова внутри фразы учитываются с недели её введения. Новые LX вводятся YAML-пакетами с cefr: unverified.
- В spoken на A1, A1+ и A2 обычные сокращения; gonna, wanna и остальные слияния из раздела 8a спецификации — с A2+. Части сокращения получают отдельные маркеры: [T8]I[/][D1]'m[/], [D1]is[/][X1]n't[/].
- У первой реплики истории есть настроение music; роли, эмоции и музыка берутся из voices.yaml. После правок: load_content, audit_course без ошибок, все тесты; проверить неделю и историю на компьютере и 390 px. Для аудиофайлов есть --all --engine test; результат этого режима — тоны, не проверка произношения.
- Истории A1+ и выше: знакомых слов не меньше 95% (`STORY_KNOWN_SHARE` в `apps/publishing/audit.py`; у A1 — 90%). Тексты нового уровня повторяют прошлый: цель — 70% его единиц встречаются хотя бы 2 раза; отчёт «Повторение A1 в A1+» в `audit_course`.
- Новые слова не повторяют уже изученные ни целиком, ни как форму (went — форма go, а не новое слово); второе значение — только с `grammar_features: [new_sense]`. Проверка: `audit_duplicate_words` в `apps/publishing/audit.py`.
