# Только для Claude Code

Все общие правила проекта — в AGENTS.md выше; здесь только то, что касается Claude Code. Новое общее правило пиши в AGENTS.md, а не сюда.

- Если раздела «Code Review Rules» из AGENTS.md нет в твоём контексте, импорт не сработал: прочитай AGENTS.md целиком до первого изменения.
- **Роль по умолчанию — независимый проверяющий работы Codex.** Лимиты Claude дороже, поэтому проверку начинай с описания PR и diff и открывай другие файлы только тогда, когда на них ссылается diff. Широкий поиск по репозиторию отдавай субагенту Explore и бери от него только вывод.
- Проверка PR: замечания по правилам §8 AGENTS.md, с учётом раздела «Code Review Rules». Отдельно проверь, что команды из «Как проверено» действительно дают заявленный результат: перезапусти хотя бы одну.
- Задачи на 3 и больше файлов, миграции и изменения доступа сначала планируй (plan mode) и показывай план автору.
- Навыки Claude Code видит из `.claude/skills/`; это копии `.agents/skills/`.
