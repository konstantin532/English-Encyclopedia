# English Encyclopedia

Интерактивная энциклопедия и курс американского английского A0–B2+ для русскоязычных учеников.
Новый девиз: «Учи английский правильно. Не так, как в российских школах».

Стек: Django 5.2, PostgreSQL на Supabase (локально SQLite), шаблоны Django, чистые CSS и JS, GSAP. Шрифты и GSAP лежат в проекте.

## Запуск на своём компьютере (Windows)

Самый простой путь: дважды щёлкните `start.bat`. Он поставит uv (если его нет), установит зависимости, подготовит базу, загрузит уроки и откроет сайт. Администратора для `/admin/` создаёт `create_admin.bat`.

Вручную (PowerShell):


1. Установите [uv](https://docs.astral.sh/uv/): `powershell -ExecutionPolicy ByPass -c "irm https://astral.sh/uv/install.ps1 | iex"`
2. В папке проекта:
   ```powershell
   uv sync
   copy .env.example .env
   uv run python manage.py migrate
   uv run python manage.py load_content
   uv run python manage.py createsuperuser
   uv run python manage.py runserver
   ```
3. Откройте http://127.0.0.1:8000

Без `DATABASE_URL` в `.env` используется локальная база SQLite: Supabase для первого запуска не нужен.

## Недели вокруг ситуаций

Уровень A1 наполнен полностью: 14 недель, 28 уроков, 5 историй и 500 учебных единиц. Недели 1–4 — пилот «курс через историю» (знакомство, новый дом и кот Box, кафе, семья на фото). Недели 5–14 продолжают сюжет: магазин, кафе Мии и пропажа Box (история 2), профессии, дорога к мастерской и старый ключ (история 3), телефон и диктовка по буквам, выходные, врач, почта и письмо без имени со словом Rose (история 4), курсы русского у Анны, поездка на автобусе и фото большой семьи за шкафом (история 5). Последний урок недели 14 — итог всей грамматики A1. Следующий уровень, A1+, пока помечен «готовится».

Над диалогом недели может стоять короткое русское вступление, а под заданием в жизнь — раскрывающийся блок «Чем всё закончилось» (story_beat). Улики и ответы истории звучат только в английских репликах.

Пилот: концепция — docs/superpowers/specs/2026-10-14-story-course-design.md, план и журнал — docs/superpowers/plans/2026-10-14-story-course-pilot*.md, материалы ведущего и контрольные пробы — docs/pilots/a1-four-weeks/. Сайт и пробы готовы, но испытание на людях не проведено, а настоящие голоса недель 3–4 ещё не прослушаны. Четыре недели A1 — первые самостоятельные шаги, а не понимание фильмов без перевода.

На странице недели идут цель «Я смогу…», диалог, уроки, готовые фразы, «Сыграть роль», скороговорка, задание в жизнь и повторение. Ученик может сохранить личную отметку «Получилось» или «Ещё нет». Список недель: /levels/a1/; первая неделя: /levels/a1/weeks/1/.

План ситуаций и грамматики — content/manifests/weeks_plan.yaml. Диалоги и скороговорки — content/seed_weeks/*.yaml. Фразы входят в seed_lexicon как единицы типа phrase; их слова известны с недели введения фразы.

## Озвучка: истории, диалоги и скороговорки

Дважды щёлкните generate_audio.bat. Он ставит пакеты синтеза речи, один раз скачивает модель Kokoro (около 310 МБ, в папку models/), озвучивает истории, диалоги недель и скороговорки и обновляет базу.

- Голоса, эмоции и настроения музыки — content/manifests/voices.yaml: один герой = один голос на весь курс.
- У реплики script есть speaker, text с разметкой, необязательные emotion, ru и spoken. Вариант spoken читает темп «Как в жизни»; медленные темпы читают text.
- Переключатель «Как написано / Как говорят» показывает оба варианта, выбор хранится в ee-speech-mode. В уроках после слоя 5 есть таблица «Как сокращают» (contractions).
- История может менять настроение музыки по репликам (music). Музыка приглушается под голосом, у неё отдельный регулятор; громкость сохраняется в ee-music-volume.
- Три темпа: «Очень медленно», «Медленно», «Как в жизни». Плеер позволяет скрыть текст, показать его без маркеров или с разметкой, заглушить выбранного героя и сыграть его роль.
- Результат: static/audio/stories/sNN/, static/audio/weeks/<level>-wNN/, static/audio/twisters/tNNN/; тайминги и пути хранятся в manifest.json. Фон сцены — static/audio/ambience/.
- Пока произношение не прослушано человеком, в манифесте стоит "verified": false.

Озвучка контрольного пакета пилота (только в static/audio/pilot-a1/): `uv run python scripts/generate_pilot_audio.py --output static/audio/pilot-a1`.

Для автоматической проверки без Kokoro: `uv run python scripts/generate_story_audio.py --all --engine test`. Тестовый движок создаёт служебные тоны, а не речь; записи нужны для проверки файлов и плеера. Перед обычной озвучкой уберите тестовые записи из static/audio/ или перегенерируйте их через generate_audio.bat.

## Подключение Supabase

1. Создайте проект на supabase.com.
2. Project Settings → Database → Connection string. Для сайта — адрес пулера (порт 6543), для миграций — прямой (порт 5432).
3. Пропишите `DATABASE_URL` в `.env` и выполните `uv run python manage.py migrate`.

После каждой миграции на PostgreSQL включается RLS на всех таблицах схемы `public`. Политик нет намеренно: Data API Supabase (роли anon и authenticated) не видит ничего, а Django работает владельцем таблиц и видит всё. Пароли, сессии и прогресс учеников не утекут через публичный API.

## Проверка готовности A1 перед A1+

A1 содержит 500 единиц, но это не означает, что все значения подтверждены по CEFR или что эффективность курса уже доказана на учениках. Структурный отчёт (14 недель, 28 уроков, 500 единиц, истории, стихи, скороговорки и дополнительные миссии):

```powershell
uv run python scripts/a1_readiness.py
uv run python scripts/a1_readiness.py --strict
```

Содержательные критерии качества, испытания с людьми и порядок работы над A1 описаны в [плане фундамента A1](docs/plans/2026-10-18-a1-foundation-before-a1plus.md). Отчёт не является сертификатом CEFR и не проверяет произношение автоматически.

## Повторение ошибок через два дня (пилот A1)

Первые восемь уроков A1 получили тематическую обратную связь и отложенную практику. Переключатель глубины чтения пока включён только для уроков 1–4. При **проверяемой** ошибке зарегистрированному ученику назначается пять других оригинальных вопросов на тот же навык **через 48 часов**, а не сразу. Задания находятся в личном кабинете → «Повторить ошибки». Если в пятёрке остались ошибки, следующий цикл назначается ещё через два дня. Тот же вопрос не выдается немедленно в общем повторении.

При свободном переносе несовпадение с подготовленным примером — ещё не ошибка: система честно помечает «нужна проверка» и не назначает штраф. Самостоятельная пятёрка не подтверждает CEFR. Всего в пилоте 43 исходных упражнения и 215 дополнительных вопросов. Миграция для расписания: `apps/learning/migrations/0004_mistakereview.py`. Остальные уроки не менялись.

## Оформление «Студия»

Все публичные страницы, регистрация, вход и личный кабинет используют светлый каркас с боковой навигацией. Стиль находится в `static/css/studio.css`, поверх общих компонентов; шрифты Golos Text, Literata и Gentium Plus остаются локальными. В словаре есть поиск по английскому слову и русскому переводу (совместим с фильтрами уровня и категории). В уроке можно менять размер текста от 15 до 24 px. Цветные маркеры сохраняют существующую систему классов и линий; их переключатель работает как прежде.

## Формат разметки

`[S1]mother[/]` — буква категории и номер класса. Можно добавить цвет: `[S1-#d32f2f]mother[/]`. Цвет сверяется с реестром, и расхождение считается ошибкой контента.
